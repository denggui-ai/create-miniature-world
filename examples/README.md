# 本机试用输入与历史边界

`clothespin-public-domain.jpg` 是可再分发的真实木夹子照片。主角是前景被手指按开的浅色木夹，背景还有其他夹子；选择主体时不要将它们合并。原图有手指支撑开合状态，去掉手指后要重新判断摆放，不能默认悬空张开仍合理。

试用时不指定跷跷板：让Skill自主选择这个商品适合的情境。商品尺寸未知，不认证精确模型比例。此照片用于检查安装和操作闭环，不是承诺成功的固定模板。

## 既有试验摘要

| 案例 | 观察结果 | 不应推导的结论 |
| --- | --- | --- |
| 直尺冲线 | 历史用户认可效果，独立读图者读出跑者接近横带 | 尺面数字准确、具体商品保真、自动策划稳定 |
| 线圈笔记本停车 | 用户认可方向，装订圈与车架关系可读；锁车动作未确定 | 所有笔记本都适合这个故事 |
| 剪刀冰场 | 用户反馈没看懂，新增冰面承担了主要线索 | 所有剪刀创意均不可用 |
| 木夹子跷跷板 | 闭合后落地更可信；人物缩小后也可能读作坐着聊天 | 物理合理就等于故事有趣、已获用户认可 |

以上为历史文字记录，不附旧图，不是本发布候选在用户电脑上的新测试结果。
