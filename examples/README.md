## 本机试用输入

`clothespin-public-domain.jpg` 是可再分发的真实木夹子照片。主角是前景被手指按开的浅色木夹，背景还有其他夹子；选择主体时不要合并。去掉手指后要重新判断支撑，不能默认悬空张开仍合理。

试用时不指定跷跷板，让Skill自主选择情境。商品尺寸未知，不认证精确模型比例。这张照片用于[本机流程验收](../docs/LOCAL_TEST.md)，不是承诺成功的固定模板。
