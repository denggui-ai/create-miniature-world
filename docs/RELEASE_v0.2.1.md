# v0.2.1 · 典型款门槛与底图准入按作者原话校正

日期：2026-10-21。小版本，运行范围仍为11文件，只改3个文件（SKILL.md、references/picture-card.md、references/making-route.md），其余8个与 v0.2.0 相同；历史版本及附件保留。

## 本次变化

三处改动都对照田中达也2017年 [Sony α Universe 访谈](https://www.sony.jp/ichigan/a-universe/news/151/) 原文：

- **图卡门槛由三条变四条**，新增“物件是典型款，身份与实际大小一眼可读”。作者原话「モチーフのサイズが伝わらないと見立てが成り立たない」（物件的大小传达不出来，见立就不成立）、「文房具や道具の場合は典型的な形を探します」（文具和工具要找典型的形）。认不出的新品、怪款不出图，建议换典型物件或换部位。
- **底图准入“物件填画”改为“物件在画中大”**：近端出画或边缘接近画边，四周可留承托面；整件小小地摆在一片纸中间仍不准入。原句“物件横贯画面，四角只剩承托面”与作者拍时留白相反，作者原话「余白を設けて真ん中にポツン」「引きで全体を撮った後に人形の周囲だけトリミング」（先留白拉远拍全体，再只裁人偶周围）。SKILL.md 反馈表“不像小人国”一行随之改为“物件在画中大”。
- **米白与裁切**：“亮的米白纸面是作者最常见的桌面”改为“米白底色（作者拍过曝白底后期统一成米色，不是米白纸）”，依据原话「背景を白飛ばしで撮影して後でベージュを乗算」；画幅与后期新增“物件小、事件读不出时可裁切收紧到事件，与原图同交”，默认仍交原图、不做后期，不靠裁切冒充指定比例。

不改：看图两问、田中案例卡、制作路线骨架、人偶参考、`photo_finish.py`、Codex 界面元数据。

## 安装与核验

下载 `create-miniature-world-v0.2.1.zip` 和同名 `.sha256`，同目录执行：

```sh
shasum -a 256 -c create-miniature-world-v0.2.1.zip.sha256
```

先读[离线指南](USER-GUIDE.html)。本包为 **guide-required**；只安装 `skills/create-miniature-world/` 的11个运行文件。从 v0.2.0 升级只需替换上述3个文件，已有安装先完整备份到技能发现目录之外；从 v0.1.4 及更早升级时仍须删除旧的4份参考文档（creative-method、photo-styles、figure-framing、creative-relations）。MANIFEST.json记录来源提交与逐文件摘要；校验值应来自可信渠道。
