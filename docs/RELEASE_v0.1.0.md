# v0.1.0 · 微缩摄影 Skill

发布稿；正式 Release 尚未创建。安装源与调用标识仍为 `create-miniature-world`。

## 本版行为

- 从物品名称或真实商品照片自主提出不同关系的候选并选案；有商品图时保留可见外观，只要提示词/先看方案时不调用生图。
- 两条拍法：默认“田中风格”，要求实拍感/光影感时使用“实拍光影”。两条保持同一创意方法与商品事实边界。
- 人偶默认约画高9%；普通分支田中上限12%、实拍上限15%，物件长边1/5为副指标。不认证真实毫米或精确模型型号。
- 包内三张作者实拍人偶照片作涂装参考；实际传入参考图，服装/活动/比例不照搬。照片为CC BY-NC 4.0，独立于代码/文档MIT。
- Python 3、Pillow与NumPy可用时另存本机颗粒/轻景深版，保留原图；已有虚化时不加深。缺依赖或透明度不可靠时交原图，不自行安装依赖。

## 已验证范围

macOS Codex本机的参考图生成、用户点名编辑及保存已有实际记录。2026-10-13源码冷启动名称输入4张，用户判基本过关；真实刨丝器参考两张，用户明确商品外观、故事、人物尺度、美感均通过。[原照与双路线样张](../examples/GRATER_VALIDATION_20261013.md)包含输入、原图、后期、署名及SHA。

Claude Code项目级安装与方案输出在2026-10-09验收；该宿主当时无内置生图，当前两条新拍法未另做Claude Code测试。

## 已知限制

- 准确文字、全部SKU结构、微孔/纹理、隐藏面、精确人偶型号和物理比例仍不保证；局部孔/划痕重绘和遮挡已列入样张说明。
- 16位RGBA TIFF可能经Pillow降位深后丢失Alpha，是已接受的非阻断限制；这类输入应保留原图，不运行本机后期。高位深PNG保护不等于所有格式透明度都已验证。
- 不把四张名称图或两张真实参考图推广为跨商品统计成功率、全自动创作质量或全Skill自演进闭环。
- 新机安装/自动触发、Windows/Linux宿主生图、Claude Code新拍法以及升级/卸载后的宿主缓存刷新均未在本轮实际验证。
- 生图能力、图片引用、编辑和额度由宿主提供；Skill不附带模型、账号、密钥或付费API客户端。没有工具时只交方案/提示。

## 获取与开始

仓库：https://github.com/denggui-ai/create-miniature-world 。当前下载渠道仍是仓库及rc2 pre-release，正式版安装附件待发布。

先阅读[离线用户指南](USER-GUIDE.html)或[安装说明](INSTALL.md)，检查已有同名版本，先用“先给方案，不要生图”的文字冒烟确认加载。安装不自动更新已有同名目录，输出与输入不会因为卸载Skill而删除。
