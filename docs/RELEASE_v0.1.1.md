## 安装与核验

下载 `create-miniature-world-v0.1.1.zip` 和同名 `.sha256`，同目录执行：

```sh
shasum -a 256 -c create-miniature-world-v0.1.1.zip.sha256
```

先读 [离线指南](USER-GUIDE.html)。本包为 **guide-required**，沿用独立 ZIP 安装包；唯一安装源为 `skills/create-miniature-world/` 的11个运行文件。已有安装先完整备份到技能发现目录之外。源码 eval、CHANGELOG 和私有日志不入运行包。MANIFEST.json 给出来源与逐文件摘要；校验值须来自可信渠道。
