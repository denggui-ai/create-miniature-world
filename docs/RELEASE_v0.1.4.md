# v0.1.4 · 创意策划与摄影联动

日期：2026-10-19。维护版本，运行范围仍为11文件；历史版本及附件保留。

## 变化

- 候选只做足以比较的粗构图；选定后再细化机位、尺度、观看顺序、布光与清晰范围，传入生成提示并对实际结果分项评估。
- 自主选品考虑观众对形态、用途和尺度的经验；用户指定商品不擅换。陌生商品、无人、局部、延迟识别与多义均可成立，不固定人数、比例或故事。
- 选案说明具体发现或感受；可见、可拍或漂亮不能单独证明值得生成。已知矛盾改变行动，弱案不凑数投入。
- 摄影重心围绕表达组织，风格名不绑定单一拍法；保留原物与模型的材质层级，允许必要衣饰，避免无依据的精细化和做旧。
- 无人后期不固定人偶脚下作为焦点；后期脚本仅focus-y帮助文字变化，算法不变。生成数量、用户选图及共享一次编辑预算不变。

## 验证与限制

本版把候选粗构图、选案、详细拍摄与实际评图串联；选品兼顾观众经验，摄影重心服务发现或感受，风格名不绑定单一拍法。当前主会话完成3项文字试用及1项校准检查，随后对榨汁器生成3初图、冰格生成1初图，均无编辑。冰格初图获用户“这个效果不错”的整体认可；不认证精确SKU、人偶造型或稳定成功率。Codex与Claude两套项目安装各11文件已核对；没有本版新会话、盲测或跨机验证。

48条源侧行为定义不等于48次执行。文字试用与成图评价均为知情主会话过程；用户认可仅覆盖冰格本张整体效果。商品结构、人偶造型和风格仍有不确定性。没有旧新版同条件盲测，不宣称稳定提升、生产就绪或全技能闭环自演进；Claude历史环境无内置生图，本轮仅文件同步。

本轮研究原作、商品参考、新生成图、提示和私有日志不随包公开。发布阶段不追加生图或独立模型调用。发布检查的实际结果以维护者收据为准；系统creator校验因环境缺PyYAML未通过，兼容格式、源侧规范和runtime检查另行记录，不能混称同一检查通过。

## 安装与使用

本包为 **guide-required**，先读[离线指南](USER-GUIDE.html)，备份已有安装，只安装skills/create-miniature-world的11运行文件。校验安装包：

```sh
shasum -a 256 -c create-miniature-world-v0.1.4.zip.sha256
```

MANIFEST.json记录公开来源提交及逐文件摘要；校验值需来自可信渠道。先请求三个简短方案，再选定生成；创意认可不等于商品可定稿。图像调用依赖宿主已有工具和额度，不新增账户、服务或付费API。
