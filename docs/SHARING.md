## 中文简介

**名称：** 微缩摄影 Skill · Miniature World
**一句话：** 给 Codex 与 Claude Code 用的创作 Skill，从日常物件的形状和结构里构思微缩场景，再用当前环境可用的图像工具生成或编辑。

**简短介绍：** 输入一个物件名称或一张商品照片，构思相机位置、人物动作和物件联想。首次试用建议明确说“先看文字方案，不要生成图片”，再选一案生成；直接要求制作时，默认两个创意各一张，用户指定数量或创意优先。没有图像工具也可以只获得方案和提示词。项目提供案例、安装说明和已知限制，适合想尝试微缩场景、商品创意图或视觉叙事的人。它不是独立生图模型，网页本身不执行生图。

## English summary

**Name:** Miniature World · Miniature Photography Skill
**One line:** A creative Skill for Codex and Claude Code that turns everyday objects into miniature scene concepts, then uses image tools available in your environment to generate or edit them.

**Short description:** Start with an object name or a product photo to plan a tiny scene, including camera position and character actions. For a first attempt, explicitly request written ideas without image generation, then choose one to generate. A direct creation request defaults to two ideas with one image each; your specified idea or count takes priority. Without an image tool, use the plans and prompts only. The project includes examples, installation instructions and documented limitations. It is an agent Skill, not a standalone image model or a web-based image generator.

## 介绍时保留的边界 · Keep these distinctions

- 生成与编辑依赖当前宿主的图像工具，不附带模型、密钥或额度；没有工具时可只策划。
  Generation and editing require suitable host tools; no model, API key or image credits are included.
