## 负例库（本项目 26 张否决，按失败原因归类；来源：分析报告 §8–§16）
| 失败原因 | 样张 | 对词典的含义 |
|---|---|---|
| 观者要先理解一个机制 | 压杆开闸、装雪橇、订纸桥、吸水、推蛋糕卷、避雨水珠、冰壶、货船 | 片刻必须是现成日常场景；机制类读法即使形状对也不入表 |
| 小人改变了物件（物理不可行） | 压杆开闸 | 小人只能借用，不能驱动物件 |
| 违常理 | 汤勺 4／6／8 | "合常理"先于"有趣" |
| 只借形状、没有会心一笑 | 汤勺 3／5、剪刀借用六张 | 形状匹配不是充分条件 |
| 动作没有后果 | 架书迷途原图 | 加"下方有沟"后成立：动作要有看得见的原因或后果 |
| 没有身体或环境回应 | 订书机鳄鱼、钢喙 | 变身类必须加身体或让环境回应 |
| 性质只被展示 | 吸水带、透明顶、肋纹海面 | 性质要变成小人可用的东西 |
| 竖放当隧道 | 胶带隧道、儿童钻爬筒 | 环竖放两次没过 |
| 船浮在水上 | 汤勺船 ×2、笔袋货船 | 本项目"船"读法三次没过；田中的船靠切楔或拆环（等级 2） |
| 跨物件迁移 | 护栏从回形针迁到长尾夹 | ✅ 不保证跨物件，迁移要重验 |
