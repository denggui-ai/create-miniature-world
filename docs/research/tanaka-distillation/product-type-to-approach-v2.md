# 产品类型 → 做法 → 本项目模板 v2（L4，审计修正后，2026-10-10）

v1 的问题（审计 D 条）：约三分之一模板要求切、拆、横放或改 UI，违反商品保真；且无服装、美妆、3C、母婴等电商主类。v2 改法：**先给商品定可动等级，再按等级过滤场景行**；表以 `scene-first-dictionary.md` 的场景行为落点；可信度仍标 ★（实看）☆（词典已核查）○（仅文本）。

## 可动等级（按单品定，不按品类）
| 等级 | 允许的配置 | 典型 |
|---|---|---|
| 0 不可动 | 只能正放、整只、保留标识 | 带包装的 3C、美妆、家电、箱包 |
| 1 可翻转堆散 | 翻转、横放、倒扣、多件堆叠或散开，不改本体 | 文具、杯具、五金、玩具、部分食品 |
| 2 可切拆消耗 | 切片、楔块、拆件、撒粉、削屑 | 食材、烘焙、可拆积木（Owner 单品确认） |

定级规则：有品牌标识朝向要求→0；可以多件出镜→至少 1；食品切面展示本身是卖点→2。等级由 Owner 或商品资料确认，策划端不得自行升级。

## 使用顺序（策划端）
1. 定商品可动等级（Owner 或资料）。
2. 拆商品形状签名，查 `scene-first-dictionary.md` 商品侧反查索引 → 场景行。
3. 只取等级内、状态为"候选"的行；"假设"行只能作次选且要在方案里标明。
4. 三候选过 G1（DeepSeek flash 方案审），再生图过 G2 盲测（见 `validation-protocol-v2.md`）。
