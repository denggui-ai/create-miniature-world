# 验证协议 v2（审计修正后，2026-10-10；Owner 定：评估用 DeepSeek，最便宜档）

替换原"Owner 一人二选一"作唯一过滤的做法。三道闸门，前两道全自动、零人工，第三道 Owner 盲判；真人盲测不常设，季度一次即可。

## 通道与成本
| 闸门 | 评估者 | 看什么 | 成本档 |
|---|---|---|---|
| G1 方案审 | DeepSeek V4 **flash**（本机 MCP `deepseek_chat`，默认即 flash，唯一自动通道） | 策划端文字：三候选、推荐理由、所引词典行 | 最低 |
| G2 图盲测 | DeepSeek flash 直连 API 看图（`ds_vision.py`），再由 flash 文字对照判分 | 生成图；盲读者看不到方案 | 最低（每图 0.6–3.6k token） |
| G3 Owner 盲判 | Owner | 两臂成图打乱顺序，不告知哪张带词典条目 | 人工，但盲 |

DeepSeek 本机 MCP 工具只接文字，看图走直连 API 脚本；盲读者与生图者不是同一模型，天然隔离。

## G1 方案审（每次策划必跑）
输入：商品名＋可动等级（0 不可动／1 可翻转堆散／2 可切拆消耗）＋三候选原文＋所引词典行原文。
DeepSeek flash 回答五题，每题只答 是／否＋一句依据：
1. 推荐案是否不需要解释就能说出"小人在干什么、物件是什么、它成了什么"？
2. 片刻是否人人认识的日常场景（能用四个字以内的常用词说出来）？
3. 候选是否超出商品可动等级（要求切、拆、翻转而商品等级不允许）？
4. 所引词典行的"形状签名＋配置"是否真的出现在这个商品上？
5. 三候选的读法关系是否互不相同？
三否即退回策划端重写，不进生图。记录：`outputs/validation/G1-<日期>-<商品>.md`。

## G2 图盲测（每张成图必跑）
**2026-10-10 更新（Owner 指出 DeepSeek flash 已有看图能力，实测通过）**：不再需要 Codex 描述步，G2 单步由 `deepseek-flash` 直连 API 完成（本机 MCP 工具只接文字，看图走 `outputs/validation/ds_vision.py`，密钥从钥匙串读入环境变量，不打印不内联）。
步骤：
1. 盲读：`python3 outputs/validation/ds_vision.py <图>`，模型只看图，不给方案，按 JSON 答"小人在干什么／主物件是什么／被当成了什么"＋60 字客观描述。
2. 对照：把盲读答案与预定答案（策划端三行依据）一并交 DeepSeek flash（文字），判每题 命中／部分／未命中。
3. 记分：3/3 命中＝通过；2/3＝次选；≤1＝不通过。两臂（带条目 vs 不带）各记分，比的是命中数，不是偏好。
记录：`outputs/validation/G2-<日期>-<商品>-<臂>.json`（盲读 JSON、判分、模型名、token、秒）。

校准（2012 年原作 4 张，640px 早期小图）：
| 图 | 真值 | flash 盲读 | 判 | 秒／token |
|---|---|---|---|---|
| 120607 | 勺子架在三角座＝跷跷板／天平（文本标"秤"） | 勺子＝跷跷板，小人拉勺柄 | 命中 | 2.2／630 |
| 120611 | 蘑菇＝雨伞，躲雨 | 蘑菇＝雨伞，躲雨 | 命中 | 15／3586 |
| 120729 | 书＝跳台，马克杯＝泳池，跳水 | 书＝悬崖，走钢丝；杯子只在描述里出现 | 部分（物件对、读法错） | 4.3／1167 |
| 120803 | 张开的剪刀＝嘴（词典已核查） | 剪刀＝滑梯或悬崖，小人坠落 | 未命中 | 2.7／726 |
结论：flash 作为"第一眼"观众偏严，2/4 全中。严是好事：G2 要测的正是不解释能不能懂；但 G2 结果须与 G3（Owner 盲判）对照记录一致率，一致率低于 2/3 时不得单凭 G2 否决方案。生成图分辨率高于 2012 原作，预期命中率会高于校准值。
成本：每图 0.6–3.6k token、2–15 秒；可同时承担 L2 第二批的"第二编码者"（审计 B3），几百张在 100 万 token 内。

## G3 Owner 盲判
两臂各 ≥1 张（额度由 Owner 定，默认各 1 张以省额度），文件名打乱为 A/B，Owner 只答"更喜欢哪张、为什么"。G2 与 G3 分歧时记录分歧，不改 G2 的分。

## 入词典门槛（与 L3 一致）
一条读法要写进 `references/creative-relations.md`，需同时满足：原作来源 n≥3 且独立物件 ≥2；本项目至少一次 G2 通过且 G3 偏好一致；Owner 逐次授权。

## 不做的事
- 不让生图模型自评；不让描述者看方案；不把 G1 的"是"当作已验证。
- 不为验证新增付费通道；Codex 生图次数仍按次授权。
