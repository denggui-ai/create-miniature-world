# L2 逐张编码模板（第二批起使用，2026-10-10）

每张图一行，两位编码者（Claude、DeepSeek flash 盲读）各填一份，分歧列出后由 Claude 复核定稿。分三栏来源：**观**＝画面看到的，**文**＝标题与说明原文，**推**＝推断；每格前缀标明。空说明的篇目"文"栏写"无"。

## A. 读法槽位（喂 scene-first-dictionary）
| 栏 | 填什么 | 示例（150820） |
|---|---|---|
| slug | 六位日期 | 150820 |
| 物件 | 真实日常物品，具体叫法 | 观：十字螺丝；文：ネジ |
| 可见特征 | 被用到的那个形状／材质／性质 | 观：圆扁头＋细杆 |
| 配置 | 摆法（平放／竖放／横放／倒扣／悬空）＋切法（整只／切片／楔块／拆件）＋数量（单个／一堆／散开／成排） | 观：头朝上钉入、成排 |
| 尺度 | 物件实际尺寸区间；相对小人（≈／2×／5× 身高） | 推：头径≈小人身高 |
| 读成 | 新身份 | 观：蘑菇 |
| 片刻 | 小人做的日常事，四字内 | 观：采菇 |
| 再加的一样东西 | 让身份成立的道具 | 观：篮子 |
| 环境回应 | 背景／底面怎样回应新身份 | 观：木条当倒木 |
| 笑点机制 | 尺度反差／形状变身／物性反用／名场面引用／谐音（谐音标不迁移） | 推：形状变身＋谐音 |
| 文化可读性 | 中文受众不解释能懂？高／中／低 | 推：高 |
| 商品可动等级要求 | 0 不可动／1 可翻转堆散／2 可切拆消耗 | 推：1 |
| 场景行 | 对应 scene-first-dictionary 的行名；没有则写"新：xxx" | 采集／挖掘 |

## B. 拍摄参数（L2b，喂 SKILL 出图段，不入读法词典）
| 栏 | 填什么 |
|---|---|
| 机位 | 齐眼／略俯／俯拍平铺／仰 |
| 主光方向与质感 | 左上柔光／右侧硬光／背光／顶光；暖／冷 |
| 背光或实用光是否为读法必要条件 | 是／否（如杯底背光＝月为"是"） |
| 背景与承托面 | 卡纸颜色／实景／黑底 |
| 景深 | 浅／中／全清（记录用，不迁移） |
| 构图 | 主体位置、负空间、字幕带 |

## C. DeepSeek flash 盲读提示（第二编码者，不给标题说明）
> 你是第一次看到这张照片的普通观众。只根据画面，用中文按 JSON 答：{"object":"主物件（真实日常物品）","feature":"被用到的形状或材质特征","placement":"摆法/切法/数量","read_as":"物件被当成了什么","moment":"小人在做什么（四字内）","added":"为了成立另外加了什么","env":"背景怎样配合","scale":"物件相对小人多大","camera":"机位","light":"主光方向，是否背光"}。不确定就写"不确定"，不要猜标题。

## D. 分歧处理
- 两位编码者 read_as 或 moment 不一致 → Claude 复核原图定稿，并在"备注"记"分歧：flash 答 xxx"。
- flash 答"不确定"的槽位不算分歧。
- 统计：每批报告两者一致率（read_as、moment 两项），作为 G2 严度的参考。

## E. 汇总到词典
按"场景行"聚合：n 加 1、独立物件去重；达到状态规则（原作 n≥3 且独立≥2，或本项目 ✅≥2 且原作≥1）的行由假设升候选；新场景行按同规则建行。每批结束同步快照到 `docs/research/tanaka-distillation/` 并提交。
