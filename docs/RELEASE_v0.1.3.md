# v0.1.3 · 创意、构图与交付判断

日期：2026-10-18。维护版本，运行范围仍为11文件；旧v0.1.2及更早版本保留。

## 变化

- 取消整体变身/耗材用途的固定候选配额、特征计数、人物画高/人数与整件入画要求；支持局部、排列、图像身份、静态及无人情境。
- 机位、尺度、布光和清晰范围共同服务可见关系，不固定100mm、极浅景深或禁止补光。保留商品结构事实和参考图能力边界。
- 分清标签图形、肖像身份、词义和标题趣味；文字词义直接组织故事仍未充分核实，不写成已验证公式。
- 区分创意稿与达到本次要求的正式成片，按实际质量推荐主推/备选/待修及数量，不把生成数量当交付数量。
- 默认A/B、文字请求不生图、用户指定一案和一次编辑预算不变；参考图可能重绘商品，后期不修复保真问题。

## 验证与限制

本机Codex项目安装11文件摘要与源码一致。一次独立临时CLI会话实际读取安装入口与参考并给切蛋器三案；明确提供路径，所以不是桌面隐式发现验证。后加的交付判断单段只做静态与安装摘要检查，未重跑模型。

主会话对压蒜器、计时器、切蛋器实际生成5张初图，计时器编辑1次。计时器同向编辑后用户认为创意还不错；用户同意切蛋器A/B主交创意稿、C备选的评估。压蒜器面食联想偏弱；计时器数字方向与其他商品细节仍有重绘，均不认证严格SKU保真。图像与原作研究只作私有证据，不随包公开。

这些是辅助式有限验证，没有旧新版同条件盲测，不宣称稳定成功率、跨商品保真、生产就绪或闭环自演进。Claude项目本轮未同步或新会话实测；新机、跨系统及桌面缓存/隐式触发仍未验证。后期脚本本版未改，既有检查保留其原版本范围，不重复冒充本轮新测试。

发布检查包括源侧静态、白名单差分、运行11文件摘要、打包及干净解压、离线指南与远端附件回读，实际结果以发布收据为准。

## 安装与使用

本包为 **guide-required**。下载ZIP及同名.sha256，在同一目录执行：

```sh
shasum -a 256 -c create-miniature-world-v0.1.3.zip.sha256
```

先读[离线指南](USER-GUIDE.html)，备份已有安装；只安装skills/create-miniature-world的11个运行文件。MANIFEST.json给出公开来源提交与逐文件摘要；校验值需来自可信渠道。先请求三个文字方案，不生图，选定后再生成。创意获认可不等于商品可定稿。
