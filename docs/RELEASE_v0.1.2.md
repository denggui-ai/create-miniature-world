# v0.1.2 · 本机与公开版统一

日期：2026-10-17。固定版本以GitHub Release与tag为准；历史v0.1.1、v0.1.0和rc2标签与附件保留。

## 本次变化

- 默认两个成立且不同的创意各一张，标A/B；只有一案成立、指定创意或只要一张时只出一张。文字请求不生图。
- 先交初图，选择后有需要才编辑；整轮共享最多一次。两张都不喜欢时先诊断，新方向须有明确请求。
- 人偶用物件部位表达相对大小，参考简化模塑造型和粗糙出厂涂装。画高目标只指导构图，不认证尺度或自动触发缩小。
- 后期先按EXIF转正，支持的格式保留有效RGB ICC；不可靠组合停止，保留原图。参数校验、固定种子及禁止覆盖原件一并纳入。
- 本机源码、项目安装与公开运行范围统一为11文件；保留柔光棚拍 / Soft Studio和旧称兼容、简单准确联想优先及可见关系检查。

## 安装与核验

下载 `create-miniature-world-v0.1.2.zip` 和同名 `.sha256`，同目录执行：

```sh
shasum -a 256 -c create-miniature-world-v0.1.2.zip.sha256
```

先读[离线指南](USER-GUIDE.html)。本包为 **guide-required**；只安装 `skills/create-miniature-world/` 的11个运行文件。已有安装先完整备份到技能发现目录之外。MANIFEST.json记录来源提交与逐文件摘要；校验值应来自可信渠道。源码eval、CHANGELOG、私有日志及本轮新图不入包，包内沿用已有许可与来源的历史刨丝器对照。

本轮4条文字用例在当前会话实际应用并自评，覆盖简单联想、遥控器路径、眼镜实心结构与无人物文字请求；有预设预期，不是独立或盲测。7项后期合成测试通过，覆盖参数拒绝、零颗粒、种子、禁止覆盖、EXIF方向与ICC处理。
