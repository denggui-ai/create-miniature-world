## 安装与核验

下载 `create-miniature-world-v0.2.2.zip` 和同名 `.sha256`，同目录执行：

```sh
shasum -a 256 -c create-miniature-world-v0.2.2.zip.sha256
```

先读[离线指南](USER-GUIDE.html)。本包为 **guide-required**；只安装 `skills/create-miniature-world/` 的11个运行文件。从 v0.2.1 升级只需替换 `references/tanaka-cases.md`；从 v0.2.0 升级另替换 SKILL.md、picture-card.md、making-route.md；从 v0.1.4 及更早升级时仍须删除旧的4份参考文档（creative-method、photo-styles、figure-framing、creative-relations）。已有安装先完整备份到技能发现目录之外。MANIFEST.json记录来源提交与逐文件摘要；校验值应来自可信渠道。
