# 创意方法：从可见特征构思见立

观众先认出“这是 X”（物件被读成别的东西），再发现“连 Y 也用上了”（另一个特征、功能或状态成了事件的原因），能增加巧思。第二次识别是加分项；只有一次但准确、清楚、符合用户用途的联想，也可以成为推荐案。

## 拿到物件后

1. **先看物件，不想人。** 按“形、纹、色、层、结构件（槽、孔、弹簧、卷边、接缝、盖子）、材质行为（吸水、回弹、挤出、卷起、夹住）、使用痕迹、名字”列 8–10 条，至少 3 条是不起眼的小特征。
2. **换观看方式找读法。** 想象平放、竖放、侧放、翻面，以及在小人的尺度下，每条特征像什么、那里通常发生什么事。写成“特征 → 读法”，此时不写“某人在上面做某事”。
3. **选一个读法吃掉最多特征。** 只对上 1 个特征是联想；同时对上形、色、层、结构件中 ≥2 项，才像“它本来就是那个东西”。三个候选必须让物件承担不同角色，不能是同一块地面上换三种人物活动。
4. **找可选的转折。** 可从物件自己的功能或状态、名字双关、真实使用习惯或角色反转寻找第二层趣味。转折要能在画面里读出，不为增加解释而强行加入。
5. **让人物与特征发生关系。** 有人物时检查动作是否接触、沿着、进入或处理具体特征；现成配件只在帮助读懂时加入，最多 1–3 件。关系本身成立时允许无人物、无动作，不把人物当必需装饰。
6. **诊断与筛选：**
   - 遮住小人，物件能否读成 X？若需要人物或道具补足读法，它们是否足够简洁、清楚？
   - **替身测试**：换成木块或纸盒，是否丢失了关键的形态、材质、用途或空间关系？若几乎不变且只是放人，降低优先级；若通用构图符合用户用途且有针对性的可见关系，可以保留，不一票否决。
   - 能否一句话说清联想？不起眼的特征和转折是加分项，不是每案必备。
   - 动作的接触点、进入路径、朝向与支撑是否可见？物件上的实心区、封闭边缘、缺口等约束是否允许故事发生？不要靠标题或服装补出不存在的通路，也不要把仍可能成立的其他读法直接判错。
   - 动作是否可摆、结构是否有依据？遇到冲突先换读法；用户指定创意和允许的改造仍按主入口处理。
   - 和已选候选是否同一机制？只换职业、颜色或机位不算新案。

## 反例

“老夫妇坐在海绵上看书”“老人在海绵上骑车”“环卫工在海绵上扫面包屑”：海绵只是一块平地，没有一个特征被读成别的东西，换成木块照样成立。

## 推荐排序

先满足用户用途、商品保留项和画面可读性，再比较联想是否准确、物件特征是否真正参与、候选是否不同；特征数量与转折用于加分，不机械计数。可推荐简单但准确的联想；只有人物装饰、关系牵强或依赖长解释的方案降级或换掉。推荐理由说明具体可见关系及主要代价，不把所有候选都说成优秀。
