# 创意方法：让物件关系与摄影一起成立

从具体物件或想表达的情境均可开始。用户已选创意时直接细化；只要方案时不生成。以下依据帮助作出选择，不要求凑齐联想类别或给创意机械打分。

## 发现联系
看实际可见的形状、颜色、纹理、结构、用途、使用痕迹，以及包装图像和文字。区分可见事实与未知部分，挑能改变读法的特点；只有名称时按已知约束策划，不补写看图事实。自主选品时，同时考虑目标观众对物件形态、用途和尺度的经验，以及特点是否值得发展；不只按新奇或未测试过选择。用户已指定物件则围绕它策划。陌生程度是表达风险，不能据此一律淘汰；依赖认出原物的方案，要考虑当前取景提供的线索，或用户允许的揭晓方式。

把特点与熟悉的空间、活动、自然景象、文化记忆或感受联系起来：轮廓可对应另一种事物，结构可成为设施或路径，排列可产生秩序，材质与光影可呈现景观，图像身份可进入新的关系。转动物件、改变距离、相对尺度或取景也能产生联系；保真模式不凭空改变结构，自由模式仍遵守用户锁定项。

继续追问这种联系让观众发现或感受到什么：幽默、尺度反差、巧妙对应、静谧或发现过程均可。仅给“像什么”的名称尚未形成画面；“诗意”“有趣”也需要具体安排支持。联系薄弱时回到物件特点，尝试另一种观看或关系，不靠换职业、衣服或背景凑新案。

涉及标签时，分清依靠的是图形线条、品牌/肖像身份、文字词义，还是标题双关。条码作斑马线依靠条纹，不证明数字含义参与叙事。图像可以成为临摹、凝视或重演的对象；若需要取下或改绘标识，须符合用户允许的商品改造范围。

## 用粗构图发展候选
每案内部简记“联系｜观看价值｜粗略画面安排｜关键不确定性”。粗构图只需交代决定读法的位置、朝向、相对尺度、视点和重心；不为三个候选各做完整道具清单、布光或长提示。候选应有关系差异，而非只换摄影效果。

选择能呈现联系的片刻或空间关系。弹奏需要手与部件对应，街景可靠重复排列，合影、等待和观看也可成立。人物、完整情节、强动作和物理接触均非必需；无人时可由物件、车辆、环境或观看方式建立尺度与情境，不强加人偶。

辅助物按作用取舍，不设固定件数或只准现成配件。支架、底座和工具本身也会改变读法，加入后重看整幅画面；核查它们是在帮助发现物件关系，还是另造一个抢走主角的装置。独立布景与商品改造分开判断，需承托、通路或开口时核查依据。

## 比较、调整与选案
比较完整画面的联系、观看价值、视觉组织和实现条件，说明物件特点在新情境中承担什么，以及由此产生的具体发现或感受。关系清楚、能拍和画面漂亮分别是依据，不能代替观看价值；不按特征数或反转数量排序。替身测试只诊断替换后失去了什么，不因其他物件有同类特点就否决。

摄影推演能揭示新联系，也能暴露原方案的困难。先核对最终取景下必需关系是否仍看得见；仅靠职业、标题或不可见细节解释时，调整关系或选案。已知材料、结构或视角不支持原意时必须改变决定，不能写完风险后仍照原案推荐。用户指定创意出现冲突时说明并提出有依据的调整，不默默换题。

只选值得投入的方案，按主流程数量交付；无案成立时说明最接近方向及障碍，不凑数生成。削弱一个竞争读法不等于目标表达和趣味已成立，调整后仍需判断观看价值。

按用途选择立即辨物或先进入情境再发现原物。区分表达必需的视觉关系与允许自由理解的含义，不要求所有人得出同一句故事。多义须由画面支持；生成后偶然出现新读法时可讨论其价值，但不能用它追认原定目标成功。标题可增加趣味，分别判断图像自身与加标题后的效果。

## 让不确定性改变行动
| 不确定之处 | 生成前的处理 |
| --- | --- |
| 商品结构或新视角缺依据 | 核对参考、采用已知面；关键缺口仍在才补资料，不以“保留原样”补出未知面。 |
| 遮挡、朝向或尺度冲突 | 做必要摆位推演；改机位若破坏核心关系，返回摆位或选案。简单关系不强制建模。 |
| 表现效果需要实际图像确认 | 指定首张要观察的关系及继续、换案或停止的依据；只在既有授权与预算内测试。 |

选定后用[摄影设计与拍法](photo-styles.md)完成详细拍摄方案，再整理生成指令。能摆下不等于有趣，描述完整不等于已验证效果；一次调整不足以支持继续时如实收束，不无期限推演或加图。
