# 创意方法：从可见特征构思见立

“巧妙”= 观众经历两次识别：先认出“哦，这是 X”（物件被读成别的东西），再发现“啊，连 Y 也用上了”（物件不起眼的特征，或它自己的功能、状态、名字，成了画面里事件的原因）。只有第一次，算一般；两次都没有，算直白。

## 拿到物件后

1. **先看物件，不想人。** 按“形、纹、色、层、结构件（槽、孔、弹簧、卷边、接缝、盖子）、材质行为（吸水、回弹、挤出、卷起、夹住）、使用痕迹、名字”列 8–10 条，至少 3 条是不起眼的小特征。
2. **换观看方式找读法。** 想象平放、竖放、侧放、翻面，以及在小人的尺度下，每条特征像什么、那里通常发生什么事。写成“特征 → 读法”，此时不写“某人在上面做某事”。
3. **选一个读法吃掉最多特征。** 只对上 1 个特征是联想；同时对上形、色、层、结构件中 ≥2 项，才像“它本来就是那个东西”。三个候选必须让物件承担不同角色，不能是同一块地面上换三种人物活动。
4. **找转折。** 优先：①物件自己的功能或状态成为事件的原因（吸水 → 水被吃光；夹住 → 啪地合上；卷起 → 卷着的东西）；②名字或双关；③人们围绕这件物品的真实习惯，被小人当成正事去做；④角色反转（小人成了猎物、顾客、病人）。没有转折，最多算一般。
5. **小人做这个环境本来就必须做的事**，动作要接触、沿着、进入或处理那个特征，用现成配件 1–3 件来“签收”读法。小人是这个新世界的从业者、见证者或受害者，不是坐在平台上做自己的事。
6. **否决测试，任一不过就换读法：**
   - 遮住小人，物件已经像 X 了吗？
   - **替身测试**：把物件换成一块木头或纸盒，画面还成立吗？成立 = 直白，否决。
   - 能一句话说出“原来如此”在哪里吗？
   - 至少用了一个不起眼的特征吗？
   - 动作在现实里用模型摆得出来、物理上会发生吗？物件上没有的结构不凭空补出。
   - 和已选的候选是不是同一机制？是就换。

## 反例

“老夫妇坐在海绵上看书”“老人在海绵上骑车”“环卫工在海绵上扫面包屑”：海绵只是一块平地，没有一个特征被读成别的东西，换成木块照样成立。

## 推荐排序

先排除替身测试不过的；剩下的按“用上的特征数 + 有无转折”排序，再看能否一眼读懂。一眼就懂但没有转折的，不当推荐案。
