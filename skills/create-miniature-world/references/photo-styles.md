# 摄影设计与拍法：让观看支持创意

摄影选择顺序：**用户明确要求 → 当前表达需要 → 默认拍法**。明确点名“柔光棚拍／Soft Studio”或“实拍光影”时沿用所选起点；用户说“田中风格／田中达也风格／Tanaka-inspired”时，结合物件转译、观看体验与实物造景气质设计摄影，不把风格名直接等同柔光棚拍。没有明确拍法时，表达需要方向性光影、材质反射或环境氛围，可选实拍光影；没有此需要时从柔光棚拍开始。交付时简述实际采用的拍法，不把风格标签当成摄影已经设计完毕。

## 选定后完成拍摄方案

候选阶段只需决定读法的粗构图；所选方案再共同安排以下内容，简单画面可用几句话表达，不要求填写长表。

| 决定 | 需要明确的安排 |
| --- | --- |
| 布景与尺度 | 物件位置、朝向、支撑；人物是否必要；人偶与道具的相对大小和关系。 |
| 机位与取景 | 从哪里看、整体或局部、哪些关系同框、哪些部分隐藏或退出画面。 |
| 观看顺序 | 视觉重心及发现线索，先认物还是先进入情境；用留白、遮挡和明暗组织视线。 |
| 光线与材质 | 主光方向、明暗层次、反射与接触阴影，使商品与布景处于同一空间。 |
| 清晰范围 | 哪些关系必须同时清楚、哪些区域可以退后；不用虚化换取关键线索消失。 |

根据表达选择视角：俯视可能揭示排列与路径，低视点可能强化体量与空间，侧光可能使纹理成为景观；这是推演入口，不是固定对应。按需要核对遮挡、视线、接触与透视，不强制三维建模，也不承诺生图工具会精确执行镜头参数。

摄影可反向启发新的联系。换机位或光线后重看整个读法，若商品事实或关键关系被破坏，返回摆位或选案。商品外观准确不要求保留原照像素与反光；新视角暴露未知面时回到有依据的视角或补关键参考，不用艺术取向放宽保真。

选定后简记“表达核心｜决定读法的关键关系｜摄影安排｜商品保留项｜尚待验证的问题”，生成提示据此整理。指出承载发现或感受的画面重心，安排商品其余部分的占幅、明暗与清晰度；当材质本身承载表达时，可让材质成为重心。手工造景目标下核对原物与模型的材质层级，不为增强质感添加无依据的磨损或布料细节，也不把真实表面细节一概抹平。写具体决定意义的关系，次要细节保留空间；不能要求同一部件既保持原位置又移动，或让相互遮挡的两面同时正对镜头。

“柔光棚拍 / Soft Studio”是本项目拍法名称，历史上由项目内的“田中风格”拍法更名而来；这一命名沿革不代表作者整体风格等同该拍法，也不代表其工作流程或认可。以下为可按情境调整的起点。

<a id="田中风格默认"></a>

## 柔光棚拍（默认）
可从柔和主光、干净承托面开始，使材质与关键关系可辨。光源方向、补光、背景、机位随构图选择，用户明确的摄影要求优先。景深覆盖需要同时看清的人物、部件或标签；不要求所有区域同样清楚。后期默认 `--dof none`。

## 实拍光影
以有依据的光向、明暗、材质反射和接触阴影建立实拍感。焦段、视点、景深按关系选择，不固定100mm、几毫米景深或只清楚人物脚下；可用柔窗光或方向性阳光，也可按需要补光。不为追求真实感强制高光过曝或丢失商品标识。

人偶尺度按[人偶与取景](figure-framing.md)的证据与情境选择，不按拍法分配画高上限。只有存在可靠的清晰带依据、前后虚化有助于观看且不损害关键关系时，后期才可用 `--dof mild`；否则用 `--dof none`，已有明显虚化时也用 none。

## 后期
两条路线按[人偶与取景](figure-framing.md)“本机后期”说明另存，原图与后期版都交付；无人场景也只需读取这段技术说明，不补人物或人偶参考。用户只要原图、禁止后期，或依赖与文件条件不支持时交原图。后期只加颗粒和条件允许的轻微虚化，强度用脚本预设，不负责修复创意、遮挡、失焦或人偶造型。
