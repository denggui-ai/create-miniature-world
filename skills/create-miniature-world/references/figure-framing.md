# 人偶与取景（小人国：巨大物件、微小人偶）

适用：默认的“物件当主角、小人偶给比例”作品。用户要求人偶当主体（大比例、看得清脸）或指定了人偶比例时，按用户。与 SKILL.md 出图段冲突时，人偶外观、比例、大小、取景、焦点、光线以本页为准。

## 本质
微缩作品是小人国：日常物件是巨大的地形或建筑，人是它旁边或上面的小不点，细节本来就看不清。人偶多大是观感问题，在画面里定，不靠物理换算定。

## 大小目标（看画面，不看毫米）
田中达也手掌大小物件作品实测（23 件，目测）：人偶约占画面高度 9%（7–14%），约为画面中物件最长边的 1/8（0.09–0.16），常有 3–6 人。
- 主指标：基准人偶约占画面高度 9%，可接受 7–12%，超过 12% 为偏大。
- 副指标：基准人偶不超过画面中物件最长边（物件主体外接框的长边，不含阴影）的 1/5，提示里按约 1/10 写。两者冲突时（如长条物件横铺满画面）以画面高度为准。（2026-10-13 盲测：人偶达物件长边 15–20% 而画面高不超 12% 的图用户判过关，超过画面高 12% 的判偏大。）
- 基准人偶：与物件同一深度、站立的那个，量脚底到头顶，不含帽子和举起的手。

## 尺寸能判断与不能判断
- 能判断（用户给了尺寸、图里有可信参照、或标准件）：物理尺寸只用来选取景（全貌、局部、微距）和提示里的比例词，不换算成画面目标（没有镜头距离，物理比例换算不出画面占比）。
- 不能判断（多数商品照）：不猜毫米，不写商品毫米数。

## 分支
- 普通大小（手掌到书本大小）：整件入画，3–4 人。
- 超小物件（回形针、纽扣、戒指）：微距，物件占满画面；人偶约占画面高度 6–8%，可放宽到物件最长边 1/4；只放 1–2 人，保证动作看得清。
- 超大物件（沙发、冰箱、汽车）：不拍全貌，取一块当地形（坐垫当广场、门边当楼面），按局部执行主指标。
- 局部特写：只用主指标。

## 提示怎么写（全用肯定句）
1. 开头先定小人国：物件是巨大、最清楚的主体（实拍光影路线只写“最大”，不写“最清楚”）；人偶是它旁边或上面的几个小不点。
2. 大小：按所在分支写画面占比（普通、超大取局部、局部特写约 9%，超小约 7%），如“each figure is about 9% of the image height and about one tenth of the object's length”，再写 `tiny N-scale model railway figures`。
3. 站位：人偶站在物件上，或与物件同一深度；前景（比物件前沿更靠近镜头处）不放人。
4. 人偶外观只写一句：`tiny hand-painted matte model railway figures, too small to show any facial detail`；有参考图时加“matching only the paint of the reference photo”。不写笔触、五官、衣褶、手、溢色、发粉。
5. 取景按物件：物件按分支入画，四周留空间；人偶可略虚；不写 close-up、macro of the figure（实拍光影路线写的是“100mm macro lens”拍桌面，不是人偶特写）。
6. 动作写清接触点，人物只写身份，并写衣着颜色（如 white chef jackets）。
7. 光线与机位：先按[拍法路由](photo-styles.md)选柔光棚拍（默认）或实拍光影。柔光棚拍：一个柔和偏暖的主光从左上或右上来，像大窗或柔光箱；物件有看得出的亮面与暗面，影子柔和、短、朝同一方向，不写补光；承托面与背景受光处亮、远处略暗；机位接近人偶视平或略俯。可写如“one soft warm key light from the upper left, like a large window, no fill: the object shows a lit side and a shaded side, short soft shadows fall the same way; the off-white paper is brighter near the light and dims gently away; camera near the figures' eye level or slightly above”。景深不在提示里强求，交给出图后的本机后期。

## 有实拍参考图时
实拍参考（用户的，如 `inputs/figure-refs/`；没有时用包内 `assets/figure-refs/`，已处理好可直接传）每张有人物的图都传入一张，按姿态挑最接近的；参考人物有草帽、头带等醒目衣饰而本图身份不同时，换一张衣饰普通的。参考图应是人偶在大片纸面里很小的样子；只有满幅特写时，先按 EXIF 转正、缩小人偶、四周补纸面再传。提示里只用一句：参考图仅管涂装质感，不取它的衣服、帽子、配色、动作和大小。

## 不要写进提示
highly detailed / intricate / finely sculpted / crisp / realistic skin / lifelike face / glossy / vibrant / collectible / action figure / toy / cute / 8k；close-up 或 portrait of the figure；表情、年龄、布料、肌肉；任何五官或手的描写。

## 出图后必看图
1. 先问：一眼看上去是不是“巨大物件旁的小不点”？
2. 估基准人偶占画面高度和物件长边的比例，写进看图记录。看得清五官、衣褶记“手办感”；穿参考图衣帽记“服装移植”。
3. 按所在分支判超标：普通大小超过画面高 12% 或物件长边 1/5；超小物件超过画面高 8% 或物件长边 1/4；超大物件取局部与局部特写只看画面高 12%；实拍光影路线普通大小的画面高上限放宽到 15%。超标时用一次编辑补救，缩到目标（普通：画面高 9% 与物件长边 1/8 中较小者；超小：画面高 7% 与物件长边 1/4 中较小者；局部：画面高 9%）。缩放比例 = 目标 ÷ 实测，取各指标算出的较小值，只缩不放，且缩后不低于该分支画面高下限（普通 7%、超小 6%）；按下限算出的缩放已不小于 1 时不编辑，交付时报告（如画面高实测 15%、目标 9%，缩到约 60%）：“把所有人偶等比缩小到当前的约 N%，脚仍踩在原接触点，重做接触阴影，物件、背景和光线不变”。编辑后仍超标，交用户判断，不再编辑。
4. 数字只拦明显偏大的；过不过关以用户看图为准。
5. 本机后期（有 Python 3、Pillow、NumPy 时做；没有、成图是透明背景，或脚本无法可靠判断透明度时，交付原图并说明）：用 `scripts/photo_finish.py` 另存一张，不覆盖原图，如 `python3 scripts/photo_finish.py 原图.png 原图-finish.png --focus-y 0.6 --dof none`。`--focus-y` 填人偶脚下那一行在画面高度中的位置（0 顶、1 底）；`--dof` 按[拍法路由](photo-styles.md)选 `none` 或 `mild`，人偶上下分布跨度大时用 `none`。原图与后期版都交付，标明哪张是后期。只在用户的工作目录写文件，不改输入图。
