# 人偶与取景：尺度服务于情境

适用：默认的“物件当主角、小人偶给比例”作品。用户要求人偶当主体（大比例、看得清脸）或指定了人偶比例时，按用户。与 SKILL.md 出图段冲突时，人偶外观、比例、大小、取景、焦点、光线以本页为准。

## 本质
物件可以成为地形、设施、局部部件或观看对象；按具体关系选择人物尺度。人物相对物件的大小与人物占画高是两件事；取景可改变画高占比，不能据此单独判真实尺度。

## 相对尺度与默认构图目标
有适用于当前目标的同场景实物照时，优先核对人偶与物件的相对大小，考虑姿态、机位、深度、遮挡和物件可见范围；不同姿态不直接等高比较。独立人偶特写只提供造型与涂装，不能与另一张商品照拼出真实比例。参照不足时保持未知，不从单个案例推出固定比例。
- 构图与相对大小：不设通用画高百分比。先判断手能否够到部件、身体是否适合设施、视线能否指向对象，再选择取景；用户指定尺寸或比例优先。画高和物件外接框长边比可辅助记录，不能单独证明真实尺度。
- 基准人偶：与物件同一深度、站立的那个，量脚底到头顶，不含帽子和举起的手。

## 尺寸能判断与不能判断
- 能判断（用户给了尺寸、图里有可信参照、或标准件）：可约束人物与物件的相对尺度并帮助选取景；先核对参照是否同平面、姿态是否可比，不把物理尺寸直接换算成画高占比。
- 不能判断（多数商品照）：不猜毫米，不写商品毫米数。

## 取景与人数
整体或局部入画按关键关系和商品识别要求选择，不按物件类别固定人数。微距可帮助小物件呈现动作，大物件可取局部；局部特写需记录裁切范围，画高不代表人物相对整个物件的大小。人物前后站位随故事安排，核对透视、遮挡和接触，不禁止前景人物。

## 提示怎么写（全用肯定句）
1. 先写物件的新角色及需要看清的关系，保留适合用途的商品识别线索。
2. 大小用实际部件关系描述，例如手到刷毛、刷头高于人物头顶。有同场景实物参照时保留可比的相对大小；不把独立照片写成精确物理比例。
3. 站位与相机共同安排，使观看、动作、路径或排列清楚；检查前后深度与遮挡。
4. 人偶外观按实物出厂涂装写：这么小的人偶涂不精细，是粗糙的。可写如“factory-painted figures: flat single-color areas whose edges slightly miss where colors meet, a little paint overlapping at collars and cap brims; faces in one flat skin tone without painted eyes or brows; softly rounded molded forms with mitten-like hands; chalky matte paint”；有参考图时加“matching the reference’s factory paint”。不写精细、写实或手办类描述。
5. 取景围绕关键关系，可以局部特写；人物、部件或标签需同时清楚时，不以虚化牺牲其中之一。
6. 动作写清接触点；静态片刻写清朝向和对应，人物身份与衣着服务情境。
7. 光线与机位按[拍法路由](photo-styles.md)选择；俯拍、低视点和侧视各有用途。提示明确所需清晰范围，景深在策划时决定，后期不负责挽救被遮挡或失焦的关系。

## 有实拍参考图时
实拍参考（用户的，如 `inputs/figure-refs/`；没有时用包内 `assets/figure-refs/`）每张有人物的图都传入一张，按姿态挑最接近的；参考衣饰与当前身份冲突时换普通衣饰的。独立人偶特写提供模塑造型与涂装，衣服、配色、动作和大小由当前情境决定；同场景实拍另提供可比的相对尺度依据。保留原件；调整参考显示或补边不作为尺度校准，不改动用于尺度判断的同场景关系。

## 不要写进提示
highly detailed / intricate / finely sculpted / crisp / realistic skin / lifelike face / glossy / vibrant / collectible / action figure / toy / cute / 8k；为追求写实而增加的皮肤、布料、肌肉细节；写实五官或精细手部的描写（第4步的平涂脸、连指手除外）。

## 出图后必看图
1. 先问：人物与部件的相对大小是否支持所选情境，关键关系能否看清，是否符合用户尺度要求？不以“越小越好”验收；画高和物长比只作记录。
2. 分别记录相对尺度证据和画高构图占比。只有俯身或遮挡人物时记“无合格站立基准”，可见高度不能直接判真实尺度通过或失败。大小、巨大物件观感与造型分别判断；造型比较模塑轮廓和涂装层级，等显示高度的局部只辅助看造型，不证明实际站高或比例。缩小、失焦或颗粒不能代替造型；照片清楚或单处衣褶可见不独立判“手办感”；非情境所需的参考衣帽迁移另行记录。
3. 不单凭画高自动缩小或判实物尺度错误。有实物尺度约束时先考虑取景和摆放；用户明确要缩人时，再依据其目标和可比测量同步调整人偶及尺度道具，重建接触，保持商品。只有用户指定画高目标且姿态、取景可比时，才用“目标 ÷ 实测”估缩放；不套用通用百分比。整轮初始图仍共享一次编辑预算，与结构及用户点名修改共用，额度已用只报告。
4. 相对尺度、构图目标、造型与美感分别给结论；不把数字达标当用户验收。
5. 本机后期（有 Python 3、Pillow、NumPy 时做；没有、成图是透明背景，或脚本无法可靠判断透明度/保留颜色配置时，交付原图并说明）：用 `scripts/photo_finish.py` 另存一张，不覆盖原图，如 `python3 scripts/photo_finish.py 原图.png 原图-finish.png --focus-y 0.6 --dof none`。脚本先按 EXIF 转正；`--focus-y` 填转正后人偶脚下那一行在画面高度中的位置（0 顶、1 底）；`--dof` 按[拍法路由](photo-styles.md)选 `none` 或 `mild`，人偶上下分布跨度大时用 `none`。RGB/RGBA 的有效 RGB ICC 随 PNG/JPEG/TIFF/WebP 输出保留，其余带 ICC 的输入或输出组合停止后期，不做隐式色彩转换。原图与后期版都交付，标明哪张是后期。只在用户的工作目录写文件，不改输入图。
