## 物件与故事的联系

见立创作需要观众可感知的连接；连接可来自形状、颜色、材质、结构、用途或文化语义，这些方式不按高低排序。商品保真约束外观，不自动要求演示产品功能。静态关系、独处或没有小人的画面也可以成立。

选案时分开判断：物件为什么像另一个东西；人物或物件间的关系是否让这个读法可见；这一刻的趣味、意外或美感是否值得呈现。关系明确是依据之一，不单独决定优先级。以“物件的哪处特点让这一刻值得看”为短判断，不新增用户必填表。用户指定的创意继续按其意图执行，不能用策划者的偏好冒充用户否定。

例如刨丝器孔边供小人抓踩，已经形成形态与动作联系；增加一位保护者可以让互动可读，但不自动增加巧思。是否值得继续，应比较这个连接的趣味和画面组织，不能把比例修正当成创意升级。海绵靠色层与材质读作岛屿，也无需与清洁功能挂钩。这些是判断示例，不是两种题材的固定优劣。

剪刀冰场是一个已被用户否定的反例：空把手孔下另铺冰面，两人牵手滑行，用户仍表示故事没看懂，认为眼镜镜片可能更成立。生成了预定动作，不等于物件与情境的联想成立；此图不作成功样例。复盘假设是冰面主要由新增布景提供，原物只贡献环边。比较原物自带与布景新增的线索及其作用，但不据此禁止辅助布景、否定所有剪刀方案，或把眼镜候选提前判为成功。用户曾明确反馈没看懂；公开包保留该反馈摘要，不将其包装成成功案例。

可用替换物件的设想检查：替换后失去了哪些视觉线索或意味？共享形态的物件可能支持同一联想，不能仅因“换成打孔板或盒子也能做”就淘汰。只有派对等活动与商品毫无可见联系时，才需先建立连接；也不为证明独特而硬加剧情。

用于广告且已有传播目标时，再判断故事是否帮助记住指定商品、是否传达目标感受；趣味成立不等于广告适配。锋利金属上的攀爬可能带出紧张感，是否适用取决于具体主题。沿用指定商品选故事，不擅自换商品、编造性能或把功能演示设为所有广告的要求。

### 触感可以给行动原因，但不是唯一入口

本项目香皂“湿滑→双人滑冰”与粘毛器“粘性→鞋黏住、同伴拉”的创意都获用户认可：当物件特征能通过接触和姿态看出来时，触感或日常使用体验可以给人物行动一个原因。MUJI轴向柄粘毛滚筒缩人后仍保留牵拉与鞋部接触，v2获正向反馈，但用户随后质疑商品识别；目前是创意获认可、识别待验、纸筒／把手比例未过，不能作完整成功案例。这是两个案例的有条件经验，不证明该入口普遍更优。

反例见田中达也已查看的[Brush Up（牙刷路灯，2018-03-15）](https://miniature-calendar.com/180315)与[Towel Bath（毛巾温泉，2023-01-12）](https://miniature-calendar.com/230112)：前者靠长柄、弯颈和刷头轮廓，后者靠纹理、色层与安静的浸泡关系，无须把所有情境改成触感驱动的动作。[Soap Skating（2020-09-11）](https://miniature-calendar.com/200911)是香皂图生成后才发现的同类先例，非当时输入；粘毛滚筒亦不作独创性声明。

另做的U形横滚款是不同商品对照：云侧读图记录显示身份辨识改善、主要结构目视保持；v1更像爬坡，v2缩人并纠正横向牵拉，但“鞋粘住还是蹬住”仍有歧义。这不是消费者测试或精确保真认证，不记全项成功；1初稿＋1编辑后停止重生。固定SKU任务不能擅自换款，获准的换款须标明为对照，不能当作原MUJI商品修复；也不能虚构易撕线或毛絮来伪造商品识别线索。

## 同物件比较与形态检查

需要比较原作或判断新意时，先实际查看相关的一两件作品，区分“物件联想已有先例”与“人物、情节或构图发生变化”；情节变化可以有价值，但不等于发现新的物件联想。无需每次生成都做全网原创性检索。

比较时检查让读法成立的可见关系，而不只比较精细程度。例如纸页作被子时，纸边与肩部的距离、折边和局部起伏影响“盖被”还是“罩棚”的读法；这是该案例的判断依据，不是所有纸张场景都应压低弧度。只把与当前失败有关的调整写入提示，成图后重新判断；不将一张图的改善当成跨物件有效性的证明。

## 商品迁移条件速查

用具体外观条件说明适用范围，分别给出**创意适性**和**保真实现难度**。下表是案例支持的候选方向，不是品类白名单或成功率承诺。原作有案例、生成图获偏好、具体商品保真通过，是三种不同证据。

| 商品条件 | 候选关系与依据 | 迁移时核对什么 |
| --- | --- | --- |
| 可见纸叠与可揭起薄页 | 覆盖、掀起；Sleepy Notes | 保留薄纸、边角与叠层；纸不能变成织物。项目有复刻与协作改编认可，尚不能外推所有纸品。 |
| 装订环与相邻平面清楚 | 环作扶手或车架；Poolside、项目笔记本停车场 | 泳池还需要水面线索；全白本不能直接继承蓝色读法。附加蓝色布景要与原商品分开，不能改本体颜色来凑故事。 |
| 黄绿分层、多孔与纤维表面 | 层色作岛岸；[Sponge Island](https://miniature-calendar.com/190207/) | 白色三层海绵不具备相同色层条件，需另选读法；保留海绵材质，不改成真岩石草地。原作案例不等于本项目商品测试已通过。 |
| 可打开且内部分隔有图可核 | 展开形成收纳空间；Wardrobe Wallet | 闭合照片不能证明卡槽、窗口和内部布局；窗面不自动等于镜子。缺内图时可做外观概念，衣柜方案需内部依据。 |
| 完整宽口杯腔与杯把可见 | 围合、服务、遮蔽；[Cafe](https://miniature-calendar.com/141222/)及项目避雨图 | 侧放后杯口、杯把、杯身关系仍须吻合原物。只有直立图时，侧放是有推断的试作；精确商品交付优先取得目标姿态照片，不能用已有错误成图补证。 |
| 纹理可识别、可以正常折叠的织物 | 覆盖与身体遮挡；[Towel Bath](https://miniature-calendar.com/230112/) | 折叠仍露织物线索；多件组合不冒充单件商品，隐藏支撑保持未知。 |
| 明确重复齿槽或斜向通道 | 田垄、停放或通行；项目木梳、Escalator | 齿槽是否开放、排列方向和数量需逐款核对；直口文件盒不直接继承斜口扶梯，单次创意认可不证明部件精确。 |

本表仅支持有条件的尝试。未覆盖的物件先判断条件，不因缺案例直接判定不适用。拟人材料、复杂多物拼装可以作为另行选择的方向，不强塞入保真小人场景。

迁移时把三件事分清：正常摆放或开合、独立附加布景、改变商品本体。按已有任务授权处理，不每项重新询问。提示可以突出几项容易改错的事实，保真承诺仍覆盖其余已知事实；未知结构不转成默认许可。只在精确交付确实缺关键参考时补问，否则保留条件化候选或选择已有视角能支持的方案。

构图围绕关键关系安排：原物识别线索、人物动作和主要色彩焦点同时可见，删去争夺焦点的配景；缩小人物后重新检查动作轮廓，不用拉远镜头替代相对比例调整。按当前用户对人物大小的要求处理；不把历史测试者的小人物偏好强加给所有用户。

研究中把观察、解释和迁移假设分开；看过标题的自评不称盲测。同物件不同故事、异物件相近关系、缺少关键条件的新商品分别比较。单个偏好样张只支持该图；方法升级默认前另测陌生商品，避免把故事题材变化误当某个策划步骤的效果。

## 生活片刻与可见关系

历史直尺冲线样张的文字观察如下：木尺的刻度和直边保留文具身份，跑者在尺面上朝横跨前方的红带奔跑，两位持带者分处尺两侧。物件的新角色是跑道，片刻是接近冲线；主要线索来自方向与横带位置，不依赖表情或微小工具。未接触提示的读图者读出了这一关系，用户认可本次效果。本节为历史验证摘要，不含原始研究日志。

此图按普通直尺自由创作，只有人偶造型参考，没有具体商品原图。尺面数字存在重复、错序，1:64 仅为规划而非实测。认可故事与效果不等于数字准确或商品保真；该例验证指定情境的一次表达，不证明自动选案稳定或优于简洁提示词，不固定跑道题材与构图。

订书机看牙是历史反例：用户未读懂故事；回看可见白衣、圆镜与灯，却主要朝向外侧金属面。将夹口叫作嘴、钉嘴叫作牙，并不能替代实际关系；检查器具的存在也可能被读为机器检修。选案与审图须判断关系，而非只核对道具清单。
