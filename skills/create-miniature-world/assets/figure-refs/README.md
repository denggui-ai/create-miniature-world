# 人偶造型与涂装参考照片 / Figure sculpting and paint references

三张照片是项目作者自己拍摄的 1:87（HO）手工涂装塑料模型人偶实物，供生图时作为人偶**简化模塑造型与涂装质感**参考传入（让小人像手工涂装的塑料模型，而不是精致手办）。照片已转正、去除元数据，并把人偶缩小放在大片纸面里，可直接传入。它们不约束人偶的衣服、配色、动作或大小。
