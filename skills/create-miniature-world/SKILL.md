# 微缩造景

把日常物件转译为可读、有趣的微缩场景，让原物身份与新角色同时成立。中文沟通；用户指定语言优先。

入口只需一个物品名称或一张商品图，例如“把这个物品做成微缩摄影”。默认自主选案并出图；说“先看方案”才停在方案选择。只要提示词或文字建议时，不生图。不要求填写参数表。

## 看物件

实际查看图片，区分原商品、风格参考和待修改成图；商品事实始终以原图为准。更换物件重新识别，不确定的尺寸或结构保持未知。

- **产品保真**：有商品图或指定具体商品时默认采用。保留可见形状、部件、实心/空心结构、材质、颜色、包装和标识；正常摆放、开合、独立布景与改造本体分开判断，视角和开合需要依据。仅“变泳池”不授权挖空；明确允许改形才放开对应限制。
- **自由创作**：只有普通物品名称时默认采用，可拆分、弯曲、组合或幻想改造，仍保留用户锁定的特征。用户明确模式优先。
- **原作复刻**：先看指定原图，沿用其物件、人物、比例、画幅和布局，不强加默认3:4、1:64或额外人偶参考；标明原作来源与学习复刻。普通风格参考不等于复刻。

默认一张独立、竖版3:4、不透明背景，无新增标题、水印或品牌，保留商品原标识。用户要求覆盖默认值。仅在主体缺失/不清、多物件主角不明，或精确还原缺关键参考时问一个最小问题。

## 选情境

在调用生图前，由策划端形成三个关系不同的短候选，各说明新角色、当前片刻及一处可见连接；不要把选案交给生图工具内部完成。用户已指定创意时直接细化。

比较“物件哪处特点让这一刻值得看”，分清联想成立、情境可读和趣味吸引力。连接可来自形状、材质、结构、用途或语义，不强求功能演示、冲突或人物。结合原物识别、现有摆放和最终人物大小检查：动作朝向、接触与承托能否看见？是否只能靠微小工具、细字或放大小人理解？情境与物件持续冲突时回到选案，不靠改变商品硬凑。

选定后留下“一句片刻、关键可见关系、位置与取景”三行依据。默认只向用户简述选定画面并直接生成；“先看方案”则展示三个短方案及推荐，等待选择。

创意卡住、要比较原作、判断商品边界或复用已认可案例时，按需读[创意关系参考](references/creative-relations.md)相应章节；不全量加载研究日志，不固定套用原作，也不作未经核查的原创性断言。

## 出图

检查当前会话实际提供的读图、参考图输入和生图能力。使用当前可用的内置生图能力；若宿主提供imagegen技能则遵循它，并始终以实时工具参数为准。明确每张输入图的角色；支持参考图就实际传入，不能传入则说明，不能声称锁定商品。无生图能力时交付提示并说明未生成，不擅自切换外部服务或付费API。

生图提示只写选定场景、参考图角色、动作位置、接触支撑、光线构图及保留项，不塞入候选推演或审计过程。默认真实手工布景摄影，原物材质可触、接触阴影可信，焦点覆盖关键关系；背景和景深服务创意，人物可有可无。

有人物时，优先使用用户提供的成人或儿童模型实物参考；也可检查本地是否存在可用的 `assets/preiser-adults-reference.png` 或 `assets/preiser-children-reference.jpg`。实际查看后按年龄选用，工具支持时传入；同轮不重复查看。参考仅约束造型，不移植活动、道具或构图。小头、正常体态、细四肢、克制涂装，以整体姿势传意，避免大头玩偶与精细真人面孔。

公开包不附带第三方人偶照片。没有实物参考时，用上述造型描述继续普通创作，并简短说明“本次无人偶实物参考，造型待审”，不声称匹配真实Preiser型号；用户明确要求严格匹配实物时，先请求一张参考。用户提供的图只用于当前任务，不自动纳入公开包。

项目默认人物模型比例1:64，按已知商品尺寸安排，不为容纳人物改大商品；未知尺寸不声称精确比例。用户指定的更小人物要求优先，原作复刻按原图。这不是作者或Preiser的统一比例。人偶造型、比例计算或修正遇到问题时读[人偶实物参考](references/creative-relations.md#人偶实物参考)。

## 看图再判断

实际看整图，再看关键局部；先描述看见什么，再对照预设。分别检查：

- **物件与情境**：原物能认出吗？特征是否参与新角色？动作、位置和承托是否可见？人物服装、工具、投影落在物件范围内或预定标题，都不能单独证明关系成立。记录可能的其他读法。
- **趣味与美感**：关系明确不自动等于有趣；用户认可方向不等于独立读懂预定故事。整图重心与比例是否合适？修改局部后重新看整图。
- **事实与交付**：商品外观、文字、人物造型/尺度是否符合约束？只报告可见问题，小字看不清不判完全保真。检查实际输出再声称画幅或像素达标；不能看图则标记未复核。

明确事实或约束错误最多自动定向补一次；用户禁止重生则仅报告。每轮一次初始生成加至多一次修正，仍未通过就交付并指出问题，不静默放宽保真要求，不因主观偏好无限重生。开发时可另做不看预设的读图，日常不强制增加盲测流程。

## 接收修改

沿用主体、原商品参考、模式和已确认约束，只改用户指定部分。新要求覆盖对应旧要求。

| 用户反馈 | 处理 |
| --- | --- |
| 没看懂 | 回查物件联想、动作与空间关系；需要时重选情境，不靠加标题或堆道具宣称解决。 |
| 换个创意 / 更有趣 | 改新角色或动作关系，仍保护商品事实。 |
| 人物太大 | 保持商品尺寸，同步缩小人物及其尺度道具并重建接触；拉远镜头不能替代相对缩小，不声称仍精确1:64。 |
| 小人不像模型 | 允许替换雕塑造型，保留必要动作与接触；检查头身和四肢，不能用磨皮、换色或颗粒替代。 |
| 不像商品 / 保持原样 | 回到原商品图，按保真修具体结构；旧错误成图不是事实源，精确恢复缺关键原图才补问。 |
| 改这张 / 只改光线 | 编辑指定成图，保留原商品依据和其他要素。 |
| 不要小人 | 改用物件、环境及道具关系，后续持续无人物。 |
| 从认可图继续 | 每轮只改一个主要动作或关系，保留其他认可要素，并与基线对照。 |
| 再来三张 | 逐张独立生成，不拼九宫格。 |

在本机执行时，将输入商品图与生成结果分开保存；把新成图保存在当前项目的 `outputs/` 下并采用不覆盖已有文件的名称。按宿主实际支持的图片或文件交付方式展示，不能只报一个并不存在的本机路径。

以成图为主、说明简短，不主动附长提示或评分表。把创意认可、用户读图和商品保真分别记录；日常使用不要求用户做审计。
