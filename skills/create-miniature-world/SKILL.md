# 微缩造景

把日常物件转译为可读、有趣的微缩场景，让原物身份与新角色同时成立。中文沟通；用户指定语言优先。

入口只需一个物品名称或一张商品图，例如“把这个物品做成微缩摄影”。默认自主选案并出图；说“先看方案”才停在方案选择。只要提示词或文字建议时，不生图。不要求填写参数表。

流程（Workflow）：看物件 → 选情境 → 出图 → 看图再判断 → 接收修改；“先看方案”时在选情境后交付方案并等待选择，只要提示词或文字建议时交付文字、不生图。

## 看物件

实际查看图片，区分原商品、风格参考和待修改成图；商品事实始终以原图为准。更换物件重新识别，不确定的尺寸或结构保持未知。

- **产品保真**：有商品图或指定具体商品时默认采用。保留可见形状、部件、实心/空心结构、材质、颜色、包装和标识；正常摆放、开合、独立布景与改造本体分开判断，视角和开合需要依据。仅“变泳池”不授权挖空；明确允许改形才放开对应限制。
- **自由创作**：只有普通物品名称时默认采用，可拆分、弯曲、组合或幻想改造，仍保留用户锁定的特征。用户明确模式优先。
- **原作复刻**：先看指定原图，沿用其物件、人物、比例、画幅和布局，不强加默认3:4、人偶大小目标或额外人偶参考；标明原作来源与学习复刻。普通风格参考不等于复刻。

默认一张独立、竖版3:4、不透明背景，无新增标题、水印或品牌，保留商品原标识。用户要求覆盖默认值。仅在主体缺失/不清、多物件主角不明，或精确还原缺关键参考时问一个最小问题。

## 选情境

先读并按[创意方法](references/creative-method.md)构思三个候选；与下文冲突时以它为准（尤其推荐排序：替身测试不过的不当推荐案，一眼就懂但没有转折的也不当推荐案）。

在调用生图前，由策划端形成三个关系不同的短候选，各说明新角色、当前片刻及一处可见连接；不要把选案交给生图工具内部完成。用户已指定创意时直接细化。

比较“物件哪处特点让这一刻值得看”，优先从原物现有形态与结构中找到转译，不先靠切挖改装搭出场景；这是选案偏好，仍按所选模式和用户要求处理。三候选里至少一条走变身：不改物件，先把它的整体轮廓读成另一样东西，物件上成对的部件对应新身份上成对的部位、又长又硬的部件对应又长又硬的部位，给新身份起名；小人在新身份成立后才进场，做人在这样东西前会做的事，尺度随新身份。其余候选走借用：小人借用物件真实的材质、形状或用途，动作对着物件上一个具体的地方（坡、切面、凹槽、边缘、纹理），合常理，有动作时动作要有看得见的原因或后果；优先以小人的行动呈现物件关系，辅助道具从简；关系本身成立时也不强求人物、动作或功能演示。三候选里还至少一条从物件的耗材、用途或使用痕迹出发（如订书钉排、咖啡渍），可与变身或借用重合。结合原物识别、现有摆放和最终人物大小检查：动作朝向、接触与承托能否看见？是否只能靠微小工具、细字或放大小人理解？情境与物件持续冲突时回到选案，不靠改变商品硬凑。每条候选过两问：小人在这个位置做这件事，现实里用模型摆得出来、观众不看说明也能一眼认出吗（反例：在鞋眼里冰钓、钻进鞋里露营）？添加物只用商品、人偶和现成模型配件（树、铁轨、碎石、车辆、人群），不为单张图专门造结构（反例：插在两只鞋之间的桅杆和缆绳），也不必每个小人都拿东西。任一问不过就换候选，选案阶段换候选不占修正额度。用户已指定的创意不被这两问否决：说直接出图时照其创意出图，交付时附一句风险和一个替代；说先看方案时把替代与原创意并列。见[田中锚点](references/creative-relations.md#田中锚点)。

选定后留下“一句片刻、关键可见关系、位置与取景”三行依据。推荐案选不听解释、第一眼就能懂小人在干什么、物件是什么或成了什么的那条，要先理解一个机制才懂的放在次选（往物件里装耗材、按它本来的用法使用，这类人人见过的动作不算机制），单纯让小人坐或站在物件上的不当推荐案，片刻尽量用人人认识的日常场景。默认把推荐案与次选案各生成一张交用户挑选，用户说只要一张时才单张直出；“先看方案”则展示三个短方案及推荐，等待选择，用户选定后只生成所选一张。

选案前先把物件拆成两三个形状特征，查[形状词典](references/creative-relations.md#形状词典)取读法、片刻与道具上限；比较原作、判断商品边界或复用已认可案例时再读[创意关系参考](references/creative-relations.md)其余章节；不全量加载研究日志，不固定套用原作，也不作未经核查的原创性断言。

## 出图

检查当前会话实际提供的读图、参考图输入和生图能力。使用当前可用的内置生图能力；若宿主提供imagegen技能则遵循它，并始终以实时工具参数为准。明确每张输入图的角色；田中达也原作图片只用于读法比对，不作为生图参考图传入，用户提供时说明原因；支持参考图就实际传入，不能传入则说明，不能声称锁定商品。无生图能力时交付提示并说明未生成，不擅自切换外部服务或付费API。

生图提示只写选定场景、参考图角色、动作位置、接触支撑、光线构图及保留项，不塞入候选推演或审计过程。提示控制在约200词，保留项写成肯定句，不列禁止清单；道具用具体风格词（如复古压铸、哑光漆），不只写品类名。默认真实手工布景摄影，原物材质可触、接触阴影可信，焦点覆盖关键关系。背景与承托面默认纯色卡纸，颜色依据主体颜色、情境和人物可读性选择；实景、木纹等真实环境只在用户要求时使用。背景和景深服务创意，人物可有可无；配色与布景经验见[背景与承托面](references/creative-relations.md#背景与承托面)。

画面有人偶时，先读并按[人偶与取景](references/figure-framing.md)写人偶外观、大小、站位、焦点和光线，出图后按它检查比例（与本段冲突时以它为准）。

非原作复刻时，有人物的每张图都传入一张 Preiser 人偶实物照（官方产品照或用户实拍）作为涂装参考（用户指定其他人偶风格或不要参考图时按用户）：用户提供的、或当前项目里用户自建的人偶参考库（有索引时按索引）优先，没有时用包内 [assets/figure-refs/](assets/figure-refs/README.md) 的三张作者实拍，按该图人物的体型和姿态挑最接近的一张，儿童用儿童参考；工具支持时实际传入，同轮不重复查看。参考只管涂装质感，不移植服装、帽子、配色、活动、道具、大小或构图；满幅特写参考按人偶与取景先处理再传。姿态僵但在做具体的活（挖、搬、攀、骑、钓），很少只站着看。人物只写身份和衣着颜色（如游客、穿白衣的厨师），不写服装款式和装备。

包内参考照片只覆盖站立、弯腰、骑车三种姿态和成人体型，儿童、老人等需要用户另行提供。工具不能传入参考图、或用户不要参考图时，用一句话告诉用户只靠文字描述多半会画成写实收藏手办、不像 Preiser 模型；默认直接出图时提醒与出图同轮完成，按人偶与取景的写法出图并标“本次无人偶实物参考，造型待审”，不声称匹配真实Preiser型号；用户要求严格像 Preiser 模型时先请求参考再出图。用户提供的图和自建参考库只在本机用于造型参考，不入库、不随包发布。

人偶大小在画面里定，按人偶与取景：基准人偶约占画面高度 9%（不超过 12%）、不超过画面中物件最长边的 1/5；商品尺寸能判断时只用来选取景（全貌、局部、微距），不换算成毫米写进提示，尺寸不明时不猜毫米，不声称精确比例。提示里写明物件（或所选耗材）是画面里最大最清楚的东西、画面里只有所列物品；不为容纳人物改大商品。用户指定的人物比例或大小优先，原作复刻按原图。这不是作者或 Preiser 的统一比例。人偶造型、比例计算或修正遇到问题时读[人偶实物参考](references/creative-relations.md#人偶实物参考)。

## 看图再判断

实际看整图，再看关键局部；先描述看见什么，再对照预设。分别检查：

- **物件与情境**：原物能认出吗？它的特征是否实际参与新角色，还是仅作可替换的容器或背景？动作、位置和承托是否可见，故事需要的开口、通路或支撑有依据吗？道具是在帮助看见物件关系，还是取代它成为故事主体？人物服装、工具、投影落在物件范围内或预定标题，都不能单独证明关系成立；区分可见的结构矛盾与仍可能成立的其他读法。
- **趣味与美感**：关系明确不自动等于有趣；用户认可方向不等于独立读懂预定故事。整图重心与比例是否合适？修改局部后重新看整图。
- **事实与交付**：商品外观、文字、人物造型/尺度是否符合约束？人偶看起来是涂装塑料模型，还是写实收藏手办？只报告可见问题，小字看不清不判完全保真。检查实际输出再声称画幅或像素达标；不能看图则标记未复核。

自动定向补一次只限结构性错误（穿模、缺件、文字乱码、商品部件错位），或人偶明显超出人偶与取景的大小阈值（按其编辑缩小）；纹理、物理合理性、其余人物尺度偏差只在交付时报告，不自动消耗修正额度，等用户点名再改。用户禁止重生则仅报告。每轮默认两张初始生成（推荐案与次选案各一张），修正仍至多一次，用在用户挑中的那张上，仍未通过就交付并指出问题，不静默放宽保真要求，不因主观偏好无限重生。开发时可另做不看预设的读图，日常不强制增加盲测流程。

完成闸门（交付验收）：能看图时每张成图都实际看过、上述三项各有结论，不能看图时标未复核；结构性错误已用掉那一次修正或如实报告；成图已按宿主支持的方式展示。“先看方案”时，以展示三个短方案及推荐为完成；只要提示词或文字建议时，以交付文字为完成；无生图能力时，以交付提示并说明未生成为完成。

## 接收修改

沿用主体、原商品参考、模式和已确认约束，只改用户指定部分。新要求覆盖对应旧要求。

| 用户反馈 | 处理 |
| --- | --- |
| 没看懂 | 回查物件联想、动作与空间关系；需要时重选情境，不靠加标题或堆道具宣称解决。 |
| 换个创意 / 更有趣 | 改新角色或动作关系，仍保护商品事实。 |
| 人物太大 | 保持商品尺寸，按人偶与取景的实测缩放同步缩小人物及其尺度道具并重建接触；拉远镜头不能替代相对缩小，不声称精确比例。 |
| 小人不像模型 | 工具支持时换一张体型姿态更接近的 Preiser 实物参考并实际传入，不支持时写更具体的造型描述并标造型待审；占用那一次修正额度；允许替换雕塑造型，保留必要动作与接触；检查头身和四肢，不能用磨皮、换色或颗粒替代。 |
| 不像商品 / 保持原样 | 回到原商品图，按保真修具体结构；旧错误成图不是事实源，精确恢复缺关键原图才补问。 |
| 改这张 / 只改光线 | 编辑指定成图，保留原商品依据和其他要素。 |
| 不要小人 | 改用物件、环境及道具关系，后续持续无人物。 |
| 从认可图继续 | 每轮只改一个主要动作或关系，保留其他认可要素，并与基线对照。 |
| 再来三张 | 逐张独立生成，不拼九宫格。 |

在本机执行时，将输入商品图与生成结果分开保存；把新成图保存在当前项目的 `outputs/` 下并采用不覆盖已有文件的名称。按宿主实际支持的图片或文件交付方式展示，不能只报一个并不存在的本机路径。

以成图为主、说明简短，不主动附长提示或评分表。把创意认可、用户读图和商品保真分别记录；日常使用不要求用户做审计。
