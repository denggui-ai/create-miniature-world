# 微缩摄影 Skill · Miniature World

让熟悉物件呈现新的空间、关系和感受。默认追求微缩艺术作品的观看价值：趣味、发现、尺度反差、情绪或巧妙对应；用户要求商品广告时，按其识别与展示目标处理。中文沟通；用户指定语言优先。

入口只需一个物品名称或一张商品图，例如“把这个物品做成微缩摄影”。默认自主策划两个成立且不同的创意，各出一张交用户比较；说“先看方案”才停在文字方案选择。只要提示词或文字建议时，不生图。不要求填写参数表。

流程（Workflow）：观察物件 → 提出联系 ↔ 粗构图 → 比较选案 → 详细拍摄方案 → 出图 → 实际评图。“先看方案”时在选案后交付短方案并等待选择；只要提示词或文字建议时交付文字、不生图。已指定创意直接细化，不重新凑候选。

## 看物件

实际查看图片，区分原商品、风格参考和待修改成图；商品事实始终以原图为准。更换物件重新识别，不确定的尺寸或结构保持未知。

表达取向与商品约束分别决定：艺术表达允许静态、无人、局部取景、延迟识别与合理多义，不因此放宽已锁定的商品外观。只有名称时按名称与已知约束策划，不声称看过具体商品图。

- **产品保真**：有商品图或指定具体商品时默认采用。保留可见形状、部件、实心/空心结构、材质、颜色、包装和标识；正常摆放、开合、独立布景与改造本体分开判断，视角和开合需要依据。仅“变泳池”不授权挖空；明确允许改形才放开对应限制。
- **自由创作**：只有普通物品名称时默认采用，可拆分、弯曲、组合或幻想改造，仍保留用户锁定的特征。用户明确模式优先。
- **原作复刻**：先看指定原图，沿用其物件、人物、比例、画幅和布局，不强加默认3:4、人偶大小目标或额外人偶参考；标明原作来源与学习复刻。普通风格参考不等于复刻。

每张独立、默认竖版3:4、不透明背景，无新增标题、水印或品牌，保留商品原标识。用户要求覆盖默认值。仅在主体缺失/不清、多物件主角不明，或精确还原缺关键参考时问一个最小问题。

## 选情境

先读并按[创意方法](references/creative-method.md)发展三个关系不同的短候选。每案内部保留“联系｜观看价值｜粗略画面安排｜关键不确定性”：联系来自物件特点，观看价值说明为什么值得看，粗构图指出决定读法的位置、相对尺度、视点与重心。此时不为每案设计全部道具和详细布光，也不把选案交给生图工具。用户指定创意或候选数量时按用户。

比较完整画面，而非只比较“像什么”的名称。人物、强动作、完整情节和反转均非必需；简单对应、静态与无人作品可以成立。辅助物按解释作用取舍，不设固定件数；加入支撑和道具后重看整个读法。替身测试只诊断替换后失去了什么，不机械否决。商品事实或表达缺口必须影响推荐、摆位或方案，不能记录矛盾后仍按原案投入。

默认选两个值得生成且关系真正不同的创意，各生成一张；不能只换背景、服装或机位凑两案。只有一案成立就交一张；无案值得投入时说明最接近方向及未解决问题，不凑数生成。用户已指定创意或只要一张时只处理所选一张，不补其他图。“先看方案”展示三个短候选及推荐后停止，不把推荐当作用户已选；用户选定后按其生成或纯文字要求继续。

选定后按[摄影设计与拍法](references/photo-styles.md)细化，并留下“表达核心｜决定读法的关键关系｜摄影安排｜商品保留项｜尚待验证的问题”。区分表达必需的可见关系与允许自由理解的含义，指出最可能的竞争读法及已有区分线索。按最终尺度与取景核对；摄影产生更好联系时可返回选案，破坏核心关系时先调整。仅靠职业、标题或不可见的小工具解释的方案不能据此判通过。

不确定性要对应行动：商品结构不明先核对参考或采用有依据的视角，关键资料仍缺才补问；遮挡、朝向、尺度冲突做必要摆位推演，不强制三维建模；实际效果仍不确定时，在已有授权和预算内明确本张要观察的结果，以及何种结果支持继续、换案或停止。空间摆得下不等于值得生成，“待验证”不自动增加调用。内部依据简短保存，不增加用户表单；成图可附短标题，但不能用标题纠正画面本身的失败。

联想不足时可查[形状词典](references/creative-relations.md#形状词典)获取例子，不把词典或道具数量当必经限制；比较原作、判断商品边界或复用已认可案例时再读[创意关系参考](references/creative-relations.md)其余章节；不全量加载研究日志，不固定套用原作，也不作未经核查的原创性断言。

## 出图

检查当前会话实际提供的读图、参考图输入和生图能力。使用当前可用的内置生图能力；若宿主提供imagegen技能则遵循它，并始终以实时工具参数为准。明确每张输入图的角色；非原作复刻时，田中达也原作图片只用于读法比对，不作为生图参考图传入，用户提供时说明原因；支持参考图就实际传入，不能传入则说明，不能声称锁定商品。无生图能力时交付提示并说明未生成，不擅自切换外部服务或付费API。

商品外观准确不等于固定原照像素、机位、取景和布光；可为创意重新组织摄影，未知结构仍保持未知。明确要求像素保持时另按实际编辑能力处理。参考图生成可能重绘商品；“保留原样”等提示不等于像素保护。只有实际保留并核对原商品图层时，才能称原照保护或分层合成。未验证的合成能力先作技术试验，不默认承诺效果。要求精确保真而新视角暴露未展示区域时，先采用有依据的视角，或补关键参考；用户明确接受推测才作为概念图测试。原反光保持与新增照明等要求须相容。

生图提示从选定的拍摄方案整理，保留决定表达的关系、参考图角色、位置、接触支撑、光线构图及商品保留项；不塞入候选推演或审计过程。决定意义的支撑形态、对应和朝向写具体，次要细节可合理发挥，不能把核心布景留给生成器临时发明。
关键动作写出可见的接触面、上下或内外关系及承托；动作所需变化与商品保留项先写成一致要求，不能同时要求同一部件移动又保持原位置或路线。
提示控制在约200词，保留项写成肯定句，不列禁止清单；道具用具体风格词（如复古压铸、哑光漆），不只写品类名。
默认真实手工布景摄影，原物材质可触、接触阴影可信；柔光棚拍的焦点覆盖关键关系，实拍光影的焦点按[拍法路由](references/photo-styles.md)执行。
背景与承托面默认米白或白色哑光纸，受光有柔和明暗渐变；主体颜色、情境或人物可读性需要时再换其他纯色卡纸；实际环境或其他承托面在有助于情境且不掩盖商品关系时也可使用。
背景和景深服务创意，人物可有可无；配色与布景经验见[背景与承托面](references/creative-relations.md#背景与承托面)。
光线与机位按[摄影设计与拍法](references/photo-styles.md)遵循“用户明确要求 → 当前表达需要 → 默认拍法”；柔光棚拍与实拍光影是起点，不替代具体摄影设计。交付时简述所用拍法；本机后期按该参考的条件另存，原图与后期版都给，用户只要原图或禁止后期时按用户。

画面有人偶时，先读并按[人偶与取景](references/figure-framing.md)写人偶外观、大小、站位、焦点和光线，出图后按它检查比例（与本段冲突时以它为准）。

非原作复刻时，有人物的每张图都传入一张 Preiser 人偶实物照（官方产品照或用户实拍）作为简化模塑造型与涂装参考（用户指定其他人偶风格或不要参考图时按用户）：用户提供的、或当前项目里用户自建的人偶参考库（有索引时按索引）优先，没有时用包内 [assets/figure-refs/](assets/figure-refs/README.md) 的三张作者实拍，按该图人物的体型和姿态挑最接近的一张，儿童用儿童参考；工具支持时实际传入，同轮不重复查看。独立人偶参考提供简化的模塑身体轮廓与涂装质感；服装、帽子、配色、活动、道具、大小和构图由当前情境决定，不从独立特写移植；同场景比例参照与参考处理按人偶与取景执行。姿态按当前片刻选择，劳动、观看、等待和合影均可。允许描述影响情境、动作或轮廓的必要衣饰与装备（如工作服、鞋），仍保持简化模塑造型；不靠精细布料或装备堆叠证明身份。

包内参考照片只覆盖站立、弯腰、骑车三种姿态和成人体型，儿童、老人等需要用户另行提供。工具不能传入参考图、或用户不要参考图时，用一句话告诉用户只靠文字描述多半会画成写实收藏手办、不像 Preiser 模型；默认直接出图时提醒与出图同轮完成，按人偶与取景的写法出图并标“本次无人偶实物参考，造型待审”，不声称匹配真实Preiser型号；用户要求严格像 Preiser 模型时先请求参考再出图。用户提供的图和自建参考库只在本机用于造型参考，不入库、不随包发布。

人偶大小按[人偶与取景](references/figure-framing.md)区分相对尺度与构图占比：有适用于当前目标的同场景实物照时，优先核对人物与物件的相对大小，考虑姿态、机位、深度和遮挡；独立人偶特写只提供造型与涂装，不能给出与商品的相对大小。人物尺度由场景关系和可信参照决定，构图占比随取景变化，不设通用画高目标或人数；不能单凭画高触发缩小。尺寸不明时不猜毫米，没有可比证据时保留不确定性。焦点覆盖关键关系，商品保留足够识别线索；不为容纳人物改大商品。用户指定的人物比例或大小优先，原作复刻按原图，不从单个案例推导固定比例。人偶造型或尺度复核遇到问题时读[人偶实物参考](references/creative-relations.md#人偶实物参考)。

## 看图再判断

实际看整图，再看关键局部；先描述实际可见内容，再对照拍摄方案，不用标题或职业代替画面证据。分别检查：

- **表达与发现**：表达必需的关系是否存在，物件特点是否参与了新的空间或关系？按原定目标判断立即辨物或延迟发现，区分结构矛盾与合理多义。动作接触、支撑合理或减少一种误读，都不单独证明目标表达成立。道具不能取代物件成为全部趣味的来源。
- **观看价值**：趣味、感受或意外有何可见依据？联系清楚、画面漂亮或符合提示词不能单独证明创意成功；用户认可方向不等于独立读懂。静态与无情节作品可以成立，不强加反转。
- **摄影与人物**：重心、取景、相对尺度、透视、反射、接触与清晰范围是否支持表达？分别判断人偶大小和模塑造型，缩小、失焦或颗粒不能证明造型改善；无人物时人物项不适用。局部修改后重新看整图。
- **商品外观**：对照原参考，指出形状、部件、文字、材质的符合项、偏差与未知项。无原图或小字看不清时不认证精确保真；核对实际输出才声称画幅或像素达标。不能看图则标未复核。

保留合理的意外发现，但与原定目标是否实现分开记录，不通过改称故事追认成功；若标题参与表达，区分图像自身与加标题后的效果。联系薄弱回策划；关系被遮挡或主次失衡回摄影；商品或人物偏差处理对应制作问题。这个诊断不自动授权新一轮生成或编辑。

交付判断区分可供选案的**创意稿**与达到本次商品外观及其他明确要求的**正式成片**；创意认可不等于可定稿，尚未核查的要求标为待确认。多图按实际质量和方向差异推荐主推、备选或待修，说明建议交付数量及理由；不把生成数量等同于可交数量，不固定交两张或为凑数追加生成。保留已生成结果供比较，交付判断不自动增加生成或编辑额度。

先交初图、等待用户选择；选中后有需要才定向编辑，至多一次。可自动定向修正的范围只限结构性错误（穿模、缺件、文字乱码、商品部件错位）；纹理、物理合理性、人物尺度与构图偏差只在交付时报告，不因超过画高目标自动缩小，等用户点名再改。用户禁止重生则仅报告。每轮初始图共享一次编辑预算（结构、人偶大小或用户点名的修改共用），用在用户挑中的那张上；没有选择时不自动编辑，额度已用或仍未通过就交付并指出问题，不静默放宽保真要求，不因主观偏好无限重生。开发时可另做不看预设的读图，日常不强制增加盲测流程。

完成闸门（交付流程，不代表质量全项通过）：能看图时每张成图都实际看过、上述四项各有结论，不能看图时标未复核；结构性错误已用掉那一次修正或如实报告；成图已按宿主支持的方式展示。“先看方案”时，按用户数量展示短方案与有依据的推荐；无案值得投入则交代原因，不凑数。只要提示词或文字建议时交付文字；无生图能力时交付提示并说明未生成。

## 接收修改

沿用主体、原商品参考、模式和已确认约束，只改用户指定部分。新要求覆盖对应旧要求。

同类偏差连续出现时，下一次测试先说明实际改变的输入、工具或处理步骤，以及仍未解决的限制；只加强提示不能称为已更换制作方法。用户明确要求继续探索时可在原授权张数和编辑预算内测试，明确沿用方法及风险，不承诺已修复；未要求继续时不自动追加。用户已判失败的结果保留原结论。

| 用户反馈 | 处理 |
| --- | --- |
| 没看懂 | 回查物件联想、动作与空间关系；需要时重选情境，不靠加标题或堆道具宣称解决。 |
| 两个都不喜欢 | 先诊断原物联想、故事可读性、结构与尺度，不自动追加生成；用户明确要求新方向后再开新一轮，仍保护商品事实。 |
| 换个创意 / 更有趣 | 按这一明确请求改新角色或动作关系，仍保护商品事实；不是原轮自动无限重生。 |
| 人物太大 | 保持商品尺寸，按人偶与取景的实测缩放同步缩小人物及其尺度道具并重建接触；拉远镜头不能替代相对缩小，不声称精确比例。 |
| 小人不像模型 | 工具支持时换一张体型姿态更接近的 Preiser 实物参考并实际传入，不支持时写更具体的造型描述并标造型待审；占用那一次修正额度；允许替换雕塑造型，保留必要动作与接触；检查头身和四肢，不能用磨皮、换色或颗粒替代。 |
| 不像商品 / 保持原样 | 回到原商品图，按保真修具体结构；旧错误成图不是事实源，精确恢复缺关键原图才补问。 |
| 改这张 / 只改光线 | 编辑指定成图，保留原商品依据和其他要素。 |
| 不要小人 | 改用物件、环境及道具关系，后续持续无人物。 |
| 从认可图继续 | 每轮只改一个主要动作或关系，保留其他认可要素，并与基线对照。 |
| 再来三张 | 逐张独立生成，不拼九宫格。 |

在本机执行时，将输入商品图与生成结果分开保存；把新成图保存在当前项目的 `outputs/` 下并采用不覆盖已有文件的名称。按宿主实际支持的图片或文件交付方式展示，不能只报一个并不存在的本机路径。

以成图为主、说明简短，不主动附长提示或评分表。把创意认可、用户读图和商品保真分别记录；日常使用不要求用户做审计。
