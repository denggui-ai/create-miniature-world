**让日常物件，成为有故事的小世界。**

面向 Codex 与 Claude Code 的 **AI 微缩摄影与缩微场景创作 Skill**。受田中达也（Tatsuya Tanaka）的「见立 / mitate」创作启发，从日常物件的形状、纹理和结构出发，构思有故事的微缩世界，生成并迭代画面。自动成图需要所在环境提供相应图像工具；Codex/ChatGPT 内置生图已跑通，已测 Claude Code 环境没有内置生图，得到的是方案与提示词，出图需人工接力。

## 开始使用

1. **获取项目**：克隆仓库，或从 Code → Download ZIP 下载并解压。
2. **安装Skill**：按[安装说明](docs/INSTALL.md)选择 Codex 或 Claude Code。唯一安装源为 `skills/create-miniature-world/`。
3. **在新会话确认加载，再上传商品图**：复制下面与你的工具对应的一句。没有照片时也可以只给物品名称。

| 环境 | 安装后发送 |
| --- | --- |
| Codex | `使用 $create-miniature-world，把这张商品图做成微缩摄影，创意由你决定，给我两个不同且成立的创意各一张。` |
| Claude Code | `/create-miniature-world 把这张商品图做成微缩摄影，给我两个不同且成立的创意；没有生图工具就给对应提示词。` |

有图像工具时，默认收到 A/B 两张初图，各有短标题和一句原物联想；选 A、选 B、都不喜欢或直接反馈即可。指定创意或只要一张时先出一张；只有一案成立不凑数。选中后有需要再编辑，本轮共享一次编辑预算。两案都不喜欢时先诊断，明确要求新方向后再生成。

想先看文字，可加「先给三个方案，不要生图」；只要提示词也可直接说。已测 Claude Code 环境无内置生图，交付方案与提示词，可在你已有的图像工具生成后把结果带回评审。首次运行可用[本机验收](docs/LOCAL_TEST.md)分别确认读图、传参考图、生图、编辑和保存能力。

## 你可以怎样和它沟通

| 你说什么 | 它应该怎样处理 |
| --- | --- |
| 创意你来定，直接做一张 | 读物件、比较候选后自主选案，工具可用时生成 |
| 先看方案，不要生图 | 给三个有差异的方案，等待选择 |
| 只给我生图提示词 | 输出文字，不调用生图 |
| 人物再小一些 | 调整人物及相关道具比例，保护商品 |
| 要实拍光影感 | 改用“实拍光影”拍法：微距浅景深、单一光源、高光可冲白 |
| 只把光线调暖 | 工具支持时编辑当前图，保留故事与构图 |
| 没看懂这个故事 | 回查物件联系、人物动作和空间关系，必要时换情境 |

有商品参考图时，默认保护其可见外观；只有物品名称时，默认自由创作。每张默认竖版3:4、不透明背景。默认 A/B 各一张；指定创意或仅一案成立时一张。先交初图，选中后按需编辑；结构、尺度和用户点名修改共享整轮一次编辑预算。

## 两种拍法：田中风格 / 实拍光影

| | 田中风格（默认） | 实拍光影 |
| --- | --- | --- |
| 什么时候用 | 不提拍法时 | 说“实拍感”“光影感”“自然光”“像真的拍出来”时 |
| 光线 | 一盏柔和偏暖的主光从左上来，影子短而柔 | 只有一束窗光或低角度暖阳，没有补光，高光可冲白、暗处变暗 |
| 背景与机位 | 米白或白色哑光纸，接近人偶视平或略俯 | 100mm 微距感，机位略高于物件上沿 |
| 景深 | 商品交代清楚 | 只有人偶和接触处清楚，前后逐渐化开 |
| 人偶 | 约占画面高度 9% | 同样按约 9% 写，微距下可能略大（上限放宽到 15%） |

“田中风格”指受田中达也作品启发的明亮布景拍法，不代表作者本人的工作流程或认可。两种拍法的创意、人偶外观和商品保真规则相同。本机有 Python 3、Pillow 与 NumPy 时，Skill 会另存一张轻度后期版（细微颗粒，必要时加一点前后虚化），原图同时交付。

## 四句话，说明创作方法

- **发现联想：** 找到商品值得被重新看见的特征。
- **建立情境：** 让行动或空间关系把联想显现出来。
- **组织画面：** 让原物、新角色和整体美感同时成立。
- **判断巧思：** 用可见证据和必要对照，区分成立、好看与保真。

我们要找的是：商品的某个特征被重新看见之后，才变得有意思的情境。故事可以只是一个生活片刻；不必演示商品用途，也不必安排冲突和结局。

## 适用条件与当前限制

适合从可见的轮廓、纹理、结构或开合关系中寻找联想。商品照片优先；不能只按「文具」「食品」等品类保证成功，也不能为了故事凭空改变商品结构。

- **运行能力**：需要可读图的宿主。自动成图需要生图工具，参考图创作需要图片输入，反馈编辑需要编辑能力；Skill不附带模型、额度或付费API客户端。
- **商品保真**：标签、文字、部件和尺寸仍可能生成错误。创意得到认可，不代表精确SKU还原通过。
- **微缩人偶**：大小按画面比例定（约占画面高度 9%，像巨大物件旁的小不点），不按商品毫米数换算；姿态和涂装需看图判断。包内附三张作者实拍的 1:87 人偶涂装参考（[说明与许可](skills/create-miniature-world/assets/figure-refs/README.md)，CC BY-NC 4.0），严格匹配其他实物时需提供有权使用的参考图。比例不是作者或 Preiser 的统一比例，也不是生成尺寸保证。
- **本机后期**：需要 Python 3、Pillow、NumPy；缺依赖时只交付原图。后期只加颗粒和轻微虚化，不能补出真实的光线与反射。
- **验证状态**：v0.1.0已发布；Codex本机生成、指定编辑与保存已跑通，两张真实参考样张四维通过，本项目安装更新及新会话显式加载已验证。Claude Code已验收安装和方案输出，本轮仅核对运行文件，未重测新会话/新拍法；新机和完整宿主生命周期仍未验证。详见[验证记录](docs/VALIDATION.md)。
