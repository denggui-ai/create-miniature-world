# 独立介绍页

采用用户最终确认的温暖作品集设计：连续摄影背景、宋体大标题、斜向木梳、笔记本与薯片双列案例。首页共三个案例，修正带等其他作品留在完整案例集中。按「作品 → 方法 → 开始使用」浏览，安装区区分尚未安装与已经安装。信息顺序参考[裁光介绍页](https://denggui-ai.github.io/threadtruth-studio/)，不复制其页面素材或风格图库。

[打开介绍页](https://denggui-ai.github.io/create-miniature-world/site/) · [浏览18组图库](https://denggui-ai.github.io/create-miniature-world/site/gallery.html)。2026-10-05用户确认后，仓库已公开，GitHub Pages使用main分支根目录发布；根index.html跳转site/。

## 在本机查看

下载完整仓库后用浏览器打开site/index.html，保留相邻examples目录。无需安装依赖、构建工具或后台服务。页面提供原始案例放大、宿主指令切换和复制；不在网页内生图。

## 三种图像用途

- examples中的图片：原始案例，继续作为审图与反馈证据，不被首屏新素材覆盖。
- hero-comb.png：由原木梳案例和选定设计稿生成的无字展示适配图，用作网页背景。它不是新的真实商品保真测试。
- cover.png：1340×1174的README展示封面，恢复连续背景与宋体。它是AI排版适配图，不是浏览器截图，也不再强制使用1200×630横版。cover.html仅用于查看它。

[选定设计稿](../docs/design-reference.png)保留作视觉依据。主标题、说明、导航和按钮均为网页真实文字与交互，不把整张设计图伪装成可用网页。桌面共享背景；手机将文案、配图和操作依次排列，避免文字遮住人物。中文标题优先使用系统宋体，缺该字体时回退衬线体，字体差异待跨系统验收。
