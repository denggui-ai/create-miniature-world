# 介绍页预览

这是独立于Skill核心的静态介绍页，尚未公开上线。主案例按用户最新选择采用：修正带、木梳、笔记本、薯片。木梳与薯片均为田野题材，分别强调结构排列与食品纹理，不宣称四种互不相同的故事。

## 在本机查看

拉取或下载完整仓库后，用浏览器打开本目录的 `index.html`。保留相邻的 `../examples/` 目录，图片直接引用已有案例，不另存一份图片副本。打开 `cover.html` 可查看已导出的1200×630封面 `cover.png`。中英文README已引用封面；尚未设置GitHub仓库分享图片。

页面提供作品放大、Codex/Claude Code指令切换与复制。浏览器不允许剪贴板写入时，会选中指令供手动复制。静态页面不在网页内生图，安装说明和GitHub案例链接当前需要仓库访问权限。

待继续：桌面与390px移动端排版、四张图放大关闭、两种指令切换、复制成功与回退、安装链接、键盘焦点；公开上线时再补齐实际公开地址及分享图片元信息。当前保留noindex作为预览标记，它不提供访问控制，不代替私有部署。

## 文件

- `index.html`：单页介绍与内容。
- `style.css`：暖白底、深灰文字、低饱和绿色交互与响应式排版。
- `script.js`：指令切换、复制与图片放大；无依赖。
- `cover.html`、`cover.png`：封面预览与1200×630图片，复用修正带原图；未改动案例图片。
- `export_cover.py`：可选封面导出脚本；修改文字或排版时运行 `python3 site/export_cover.py`，仅该操作需要PyMuPDF。Skill安装与网页查看无需Python或构建依赖。

没有构建依赖、账户系统或后台。正式部署前确认发布根目录同时包含site与examples，或将图像相对路径调整为实际公开素材位置；不要单独上传site后误以为图片已经完整。

封面采用独立排版导出，已查看图片确认文字、构图和原图完整性；它不是网页截图，不能代替网页视觉验收。本轮还把案例图片尺寸改为实际尺寸，显示比例改为3:4，并将浅灰文字加深；这些源文件修正仍待浏览器复核。
